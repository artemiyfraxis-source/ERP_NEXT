# Замер переходников на Planar S50180 + АКМ

Windows PowerShell **5.1**, установленная S2VNA, обычный пользователь Windows. Python, pip и права администратора не нужны. Запускайте `start.cmd` двойным щелчком, без «Запуск от имени администратора». Перед работой завершите управляющий сеанс ВАЦ в ERP; инструмент удерживает тот же mutex прибора, что и агент ERP.

## Первый запуск

1. Скопируйте `config.example.json` в `config.json`, замените `server_url` на HTTPS-адрес вашего ERP без пути `/api`. Файл локальный, в Git не попадает. Не записывайте в него пароль.
2. Запустите S2VNA, подключите прибор, дождитесь готовности и прогрева по руководству прибора. Подготовьте тракт и бирки СИ на каждом переходнике.
3. Откройте `start.cmd`. Пункт 1 показывает готовность, серийные номера, диапазон АКМ, оба датчика ВАЦ и отдельную температуру АКМ. Логин и пароль ERP запрашиваются при первом замере за запуск; пароль скрыт и не сохраняется.

## Каждый рабочий сеанс

1. **2 — Калибровка АКМ.** Подключите АКМ к концам обоих портов и подтвердите. До изменения настроек сохраняется состояние оператора с калибровкой (`CDST`). Профиль: 10 МГц–18 ГГц, 1601 точка, ПЧ 1 кГц, 0 дБм, 50 Ом, S11/S21/S12/S22, без обработки. Определения наборов мер не изменяются.
2. **3 — Контроль нагрузкой.** Последовательно поставьте LOAD на плоскость калибровки порта 1 и порта 2. Оба максимума КСВН должны быть ≤ 1,06. Без успешного контроля загрузка запрещена.
3. **4 — Замер переходника.** Введите `СИ.035`, проверьте название, серийный номер и разъёмы. Введите `напрямую`, `слева СИ.009` или `слева СИ.009, справа СИ.008`. Для каждой оснастки подтвердите ориентацию: при обычной установке её сторона 1 направлена к порту 1 ВАЦ. Для правой оснастки это сторона, обращённая к измеряемому переходнику. Обратная установка меняет стороны S-параметров.
4. По имени карточки предлагается верх диапазона: SMA — 18 ГГц, N/TNC — 11 ГГц, BNC — 4 ГГц. Можно ввести другую частоту до предела запуска (по умолчанию 18 ГГц). Частотная сетка калибровки не меняется: результат обрезается до последней измеренной точки не выше предела. Для оснастки нужна **та же сетка** в выбранной полосе; интерполяции и экстраполяции нет.
5. Установите цепочку и нажмите Enter для **новой** развёртки. Проверьте КСВН обеих сторон и максимальные потери; подтвердите «Записать в карточку?». Файл `.s2p` добавляется как «Прочее». При совпадении имени отдельно подтверждается добавление ещё одного файла; прежний сохраняется.
6. **5** возвращает настройки оператора и отменяет текущую калибровку. **0** предлагает восстановить настройки перед выходом. Если отказались или процесс прервался, следующий запуск обнаружит резервную копию. После перезапуска нужна новая калибровка и контроль LOAD.

Для другого предела запуска: `start.cmd -FmaxHz 11000000000` (`-fmax` — синоним, единица Гц).

После переноса прибора на другой ПК или перезапуска S2VNA выберите **1**: показаны число и определения трасс, форматы, текущие шкалы, COR каждой трассы и возраст/действительность калибровки текущего запуска. Если калибровки нет, выполните **2**, затем контроль LOAD (**3**); прежний журнал сам по себе не разрешает замер. Пункт **2** автоматически ставит экран «ОТК — переход» и проверяет чтение настроек. **6 — Экран: выбрать вариант** — см. «Экраны»; исходное состояние оператора сохраняется перед первым изменением. Перед новой развёрткой коррекция COR проверяется на трассах замера 1–4 самого прибора.

## Экраны (пункт 6)

Порядок работы: экран → калибровка АКМ (**2**) → контроль нагрузкой (**3**) → замер (**4**). Пункт **2** калибрует на сетке экрана «ОТК — переход». Смена полосы, числа точек или мощности после калибровки делает её недействительной: программа пишет «Калибровка не действует — откалибруйте заново». Экраны с той же развёрткой (графики, шкалы, ПЧ, усреднение) переключаются свободно. Пункт **3** сам ставит «Проверка калибровки (нагрузка)», пункт **4** — «ОТК — переход».

Общие параметры каждого экрана: 1601 точка; ПЧ 1 кГц (вариант «точный отсчёт» — 300 Гц); 0 дБм; усреднение откл. (вариант 4×; для записи замера — только откл.); сглаживание откл. всегда — для приёмки запрещено, скрывает неравномерность; расширение портов, временная область и стробирование откл.; запуск непрерывный для просмотра, однократный для записи (программа делает это сама). Маркеры 1 / 3 / 6 / 12 / 18 ГГц. Шкала каждого графика задаётся экраном явно — от прежнего экрана ничего не остаётся.

| Экран | Полоса | Графики и шкалы (10 делений) | Линии допуска |
|---|---|---|---|
| ОТК — переход | 10–18000 МГц | КСВН S11, КСВН S22: 1,00…max(норма × 1,15; 1,20), вверх до 0,05; S21, S12: 0…−0,5 дБ (2×2) | норма СИ: КСВН и вносимые потери |
| ОТК — кабельная сборка | по ЭТК (например 1–6000 МГц) | КСВН S11, КСВН S22: 1,00–1,50; S21: 0…−3 дБ | норма КСВН сборки по ЭТК (вводится) |
| ОТК — один порт | по ЭТК | КСВН S11: 1,00–1,50; возвратные потери S11: −50…0 дБ | норма КСВН сборки по ЭТК (вводится) |
| Проверка калибровки (нагрузка) | 10–18000 МГц | КСВН S11, КСВН S22: 1,00–1,10 (S21/S12 скрыты, 0…−0,5 дБ) | 1,06 |
| Проверка кабелей (шевеление) | 10–18000 МГц | КСВН S11, КСВН S22: 1,00–1,10; S21: 0…−0,3 дБ; фаза S21: ±180° — все с графиками памяти | нет |
| Подробно (инженер) | 10–18000 МГц | 12 графиков 3×4: КСВН как «переход», S21/S12 0…−0,5 дБ, Вольперт-Смит (полная шкала 1), фаза ±180°, ГВЗ — автомасштаб после каждой развёртки, возвратные потери и обзор S21/S12 −50…0 дБ | норма СИ |

Линии нормы СИ — из нормы, назначенной этому СИ (поле norm_id ВЧ-данных карточки, каталог `rf-norms.json`; та же норма, что в паспорте), до выбранной верхней частоты: на КСВН — верхняя линия a + b·F; на S21/S12 (дБ) — нижняя линия −(a + k·√F) нормы вносимых потерь (ломаная из 12 отрезков, чуть строже нормы), у листа с испытанием на одной частоте — короткая линия на этой частоте. Без назначенной нормы (или без связи с ERP) линий нет — «норма не назначена»; id, которого нет в файле рядом с программой, — «обновите rf-norms.json»; «1,30 — требование цеха» не рисуется. В заголовке канала — номер СИ и нормы. ГВЗ S21 автомасштабируется. Нормы берутся из `rf-norms.json`: копия рядом с программой, иначе `backend/data/rf-norms.json`.

**9 — Шевеление: запомнить графики** (на экране «Проверка кабелей (шевеление)») копирует текущие графики в память; затем изгибайте кабель — видны оба. **8 — Вернуть прежний экран** возвращает графики, шкалы, маркеры, линии и заголовок до первого изменения (`data/screen-backup.json`); калибровка не меняется. **5** возвращает всё состояние оператора.

**10 — Записать экраны в файлы S2VNA** пишет по файлу на экран в `C:\VNA\Экраны\` (тип сохранения «Установки анализатора», `MMEM:STOR:STYP STATe` — без таблиц калибровки и данных) и `\State\Autorecall.sta` («ОТК — переход», загружается при каждом запуске S2VNA), если их ещё нет; существующие файлы не перезаписываются. Каждый экран ставится со своей полосой, поэтому калибровка запуска после этого не действует. Если в S2VNA включено «Автоматическое сохранение между запусками», Autorecall.sta перезапишется при выходе — выключите эту функцию. Файл экрана, загруженный в S2VNA вручную, не содержит калибровки: после загрузки — калибровка заново.

Прогрев по РЭ: ВАЦ — 40 мин, АКМ — 15 мин; программа предупреждает, если S2VNA запущена меньше 40 минут назад.

## Счётчик сочленений

Программа сама записывает в карточки СИ сочленения разъёмов (стороны A/B — порядок ВЧ-интерфейсов в карточке). Калибровка (**2**): АКМ — обе стороны, каждый кабель — сторона к изделию. Замер (**4**): изделие — обе стороны, кабели и оснастка — по показанной цепочке; оснастка, оставшаяся на кабеле с прошлого замера, к кабелю повторно не считается. Перед замером показывается ресурс: «почти исчерпан» с 80 %, при исчерпанном ресурсе нужно подтверждение. Сторона, которой нет в карточке, не считается — заполните оба ВЧ-интерфейса.

Каждый замер сначала сохраняется в `data/pending-matings/`, затем отправляется; повторная отправка того же замера в ERP ничего не удваивает. Нет связи — пакеты ждут, **7 — Отправить сочленения в ERP** повторяет отправку. Пакет, который ERP не принял (нет карточки или стороны), откладывается в `pending-matings/rejected/`. Если программа аварийно закроется между развёрткой и записью пакета на диск, сочленения этого замера не будут учтены — добавьте их в карточке кнопкой «+1 сочленение». Номера кабелей и АКМ по умолчанию — СИ.100, СИ.101 (сторона B к изделию) и СИ.104; другие задаются в `config.json` полями `mating_cables` и `mating_acm` (см. `config.example.json`).

## Защита и локальные данные

Запись запрещена, если нет хотя бы одной из четырёх трасс с `COR`, калибровка старше 4 часов, сменился ВАЦ/АКМ, неизвестны температуры или любой датчик ВАЦ ушёл более чем на 1 °C (РЭ: допустимое изменение температуры после калибровки ±1 °C). Проверка повторяется после подтверждения оператора непосредственно перед загрузкой. После неудачной повторной калибровки прежняя не используется.

Оснастка берётся только из её карточки: имя `.s2p` должно содержать «Замер ВАЦ» и номер СИ либо серийный номер экземпляра. Неоднозначный выбор требует устранить неоднозначность в карточке. Файлы кэшируются в `data/fixtures/`. Нельзя считать неизвестную оснастку идеальным трактом. Это инструмент двухпортовой характеризации; результат пары автоматически на два переходника не делится. Файлы с сопротивлением, отличным от 50 Ом, не поддерживаются.

`data/raw/` — исходные развёртки, `data/results/` — обработанные результаты с происхождением, `data/calibrations.jsonl` — попытки калибровки и отдельные результаты LOAD с общим идентификатором. `data/used-sweeps.jsonl` резервирует хеш **всех сырых точек** и идентификатор до HTTP-записи. После ошибки сети резервирование сохраняется: проверьте карточку, затем снимите новую развёртку. Не удаляйте журнал и не используйте несколько копий папки данных для одного сеанса. Один процесс на папку и один владелец прибора обеспечиваются блокировками. Не меняйте настройки S2VNA вручную во время работы.

## Учебный режим и тесты

`start.cmd -Offline` создаёт локальные **синтетические** данные, макет COM и макет ERP в `data/offline/`; реальных соединений нет. Для примера используйте `СИ.035`, цепочку `напрямую`. Результаты явно помечены учебными. Эта развёртка постоянная: повторная загрузка тех же сырых точек блокируется журналом.

Собственные данные: `start.cmd -Offline -OfflineDirectory C:\VNA\mock`. Папка содержит `device.json` (Ready, VnaName, VnaSerial, AcmSerial, AcmMinHz, AcmMaxHz, VnaTemperature, VnaTemperatures — два датчика, AcmTemperature), `sweep.s2p` с сеткой профиля 1601 точка и `instruments.json` (`{"instruments":[{"id":"...","inventory_number":"СИ.035","name":"...","serial_number":"...","files":[]}]}`). Формат файла оснастки и локальной загрузки см. в `erp.ps1`. Можно взять автоматически созданный пример и заменить значения. Исходные макеты и рабочие журналы разделены.

Из корня репозитория, только локальные моки:

```powershell
Invoke-Pester -Script tools/vna-measure/tests -PassThru -Quiet
```

Работу на настоящем приборе и HTTPS-сервере эти тесты не подтверждают; перед серийными измерениями нужна проверка оператором на станции.
