# Журнал автономных прогонов переноса

Новые записи — сверху. Каждый прогон `/migrate-next` добавляет одну запись: что взял, коммиты, состояние
`npm run check`, решения «решено агентом — проверить» и вопросы к владельцу. Владелец читает отсюда
и пушит `main`, когда устраивает.
