# Очередь переноса SUPPLYMAP → ERP_NEXT

Единая очередь для автономных прогонов `/migrate-next` (скилл `.claude/skills/migrate-next`). Прогон берёт
сверху 1–3 открытые задачи с непересекающейся зоной, делает, сливает в `main`, отмечает здесь и пишет
журнал `RUNLOG.md`. Владелец правит очередь руками в любой момент — порядок строк и есть приоритет.

`supplymapSeen: 1ec8951` — последний коммит SUPPLYMAP, отставание от которого уже разобрано в очередь.

Отметки: `[ ]` открыта · `[~] <прогон>` в работе · `[x] <коммит>` сделана · `[?] <вопрос>` ждёт владельца ·
`[!] <причина>` сорвалась, прогон её пропускает до правки владельцем.
SK-n — задачи разведки склада (WH-DISCOVER); это не строки WH-n аудита `docs/audit/codex-port.md`, совпадения указаны в скобках.
Формат: `- [ ] ID · зона · серьёзность · что сделать`. Зона — каталог модуля; две задачи с одной зоной
в один прогон не берутся, миграция Alembic — не больше одной на прогон.
