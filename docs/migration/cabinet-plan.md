# Личная карточка — план (владелец прислал концепт 04.10.2026)

Своя функция, в SUPPLYMAP источника нет (там только `prod_absences` и плоский список отделов). Вид — стиль ERP
(erp-screens), из концепта берём структуру: шапка (ФИО, должность · отдел, категория, «в должности с»), вкладки
Обзор · Подчинённость · Проекты · Задачи вне проектов · Мои заявки на покупку · Документы · Компетенции · Отпуска и
заявления · Рабочее время.

## Сделано (04.10, #185/#186)
- Фаза 1: API `GET /api/employee-card/me|{id}` (`workflows/employee_card.py`), экран «Обзор» (`EmployeeCardPage.tsx`,
  `?section=card`, из профиля и из «Сотрудников»); кадровые поля сотрудника (миграция 0085): табельный номер,
  должность, квалификация, «в должности с», руководитель, руководитель отдела.

## Фаза 2 — заявления на отпуск/отгул
- T4 (opus, миграция после текущей головы): `identity/leave.py` — норма отпуска на год (по умолчанию 28 календарных
  дней, на человека, без автопереноса), график отпусков, заявления. Статусы: черновик → подписано → согласовано
  руководителем → зарегистрировано кадрами | отклонено | отозвано. Подпись на каждом шаге: кто, когда, способ
  (повторный ввод PIN/пароля), версия и SHA-256 содержания; правка после подписи поднимает версию; себя не согласуют.
- T5 (sonnet): вкладка «Отпуска и заявления» + входящие на согласование (`LeaveApprovals.tsx`).
- T6 (opus): зарегистрированный отпуск → `production_absences` (планировщик не ставит человека), отзыв убирает;
  уведомление следующему согласующему. Запись в календарь — без затирания ручных отсутствий мастера.
- Доступ «Кадры» — новый ключ раздела `hr`, не роль. Замещающий согласующий — руководитель руководителя, иначе любой
  с `hr` edit.

## Фаза 3
- T7 (opus, миграция): документы (должностная инструкция / положение) по должности или отделу, с версиями;
  ознакомление каждой версии с записью подписи; новая версия снова требует ознакомления.
- T8 (opus): рабочее время — отработано против нормы смены по дням → переработка; отгулы из заявлений;
  долг «с отработкой».
- T9 (sonnet): вкладки Документы · Компетенции · Рабочее время.

«Инициатор заявок»; «Руководитель работ» появится, когда у проекта будет поле людей. Функциональное подчинение
(«Группа выходного контроля») — позже; сейчас прямое (руководитель, руководитель отдела, мастер площадки).
