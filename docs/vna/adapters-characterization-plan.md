# План замеров коаксиальных переходников на ВАЦ Planar S50180

Цель: у каждого переходника (СИ.014–097, ADP1A СИ.006–009) свой файл `.s2p` и сводка в карточке реестра СИ.
По ним ERP подбирает лучшие экземпляры в цепочку и вычитает переходник из замера (де-эмбеддинг в S2VNA).

**Все замеры этого плана калибруются эталоном — набором 6650F27 (СИ.003), не АКМ.** Сначала эталоном меряется всё:
ADP1A, складские переходники, перемычки, набор SMA-MF06. Потом эталон убирается на хранение и достаётся только для
контроля АКМ и перепроверок. Рабочие замеры изделий идут через АКМ, а переходники вычитаются по их `.s2p`.

## Что известно заранее (паспорта продавцов)

Полная выборка с источниками: [docs/data/rf-adapters-datasheet-2026-11-12.json](../data/rf-adapters-datasheet-2026-11-12.json).

- **ADP1A (Планар):** КСВН ≤ 1,06 до 20 ГГц, ≤ 1,10 до 26,5, ≤ 1,15 до 32 ГГц. Измерительный класс.
- **Складские (gsm-repiteri):** разъёмы и род подтверждены у всех; КСВН и потерь продавец не даёт ни на один.
  Частота у большинства указана только для серии разъёма. Отдельно заявлено: S-311 до 18 ГГц; SN-312, N-311, N-322 до 11 ГГц.
- **75 Ом — в тракт 50 Ом не ставить:** B-311, F-311, F-322. Не мерить, в карточке пометить «75 Ом».
- **Сопротивление не заявлено** (проверить замером — у 75-омного КСВН около 1,5 уже на низких частотах): ST-311, TB-322,
  TN-311, TN-322, T-311, B-312.
- **Расхождение:** на складе было две партии S-AA312 с разными названиями. Источник: RP-SMA вилка – RP-SMA розетка.
  Сверить по самим переходникам.

## Подготовка (один раз)

1. **Пометить каждый переходник его номером СИ** (бирка или маркер на корпусе): иначе экземпляры перепутаются,
   а данные ведутся поштучно.
2. **Тракт:** порт 1 и порт 2 (N розетка) → кабели C50SMNM.2 (СИ.100–101; N вилка – SMA вилка). Концы тракта — SMA вилка.
3. **Моменты затяжки:** 3,5 мм ↔ 3,5 мм — ключ из 6650F27 (0,9 Н·м). Если хотя бы одна сторона SMA — 0,56 Н·м
   (ключа 0,56 Н·м в реестре нет — купить; ключ 2–20 Н·м СИ.116 для этого не подходит).
4. **Настройки S2VNA:** 10 МГц – верх по серии (SMA 18 ГГц, N 11 ГГц, TNC 11 ГГц, BNC 4 ГГц), 1601 точка, ПЧ 1 кГц,
   0 дБм, сглаживание выкл., 4 трассы S11/S21/S12/S22.

## Порядок замеров

### Шаг 1. ADP1A и переходники SMA ↔ SMA — полный двухпортовый замер (точность эталона)

Калибровка двух портов набором 6650F27 (SOLT) **на тех родах концов, которые нужны переходнику**:
у 6650F27 есть меры вилка и розетка и все три перемычки. Нужный род конца получаем сменной стороной ADP1A
(сначала её саму охарактеризовать при калибровке на концах «вилка»).

| Переходник | Концы тракта при калибровке |
|---|---|
| ADP1A-35F-35F, S-322 (розетка–розетка) | вилка / вилка |
| ADP1A-35M-35F, S-312 (вилка–розетка) | вилка / розетка |
| S-311 (вилка–вилка) | розетка / розетка |

Сохранить `.s2p` (Файл → Сохранить данные → Touchstone) с именем по номеру: `СИ.0NN.s2p`.

### Шаг 2. SMA ↔ N, TNC, BNC и RP-SMA — парами «спина к спине» (ориентировочно)

Калибровка — тоже эталоном 6650F27 на концах SMA. Но у эталона меры только 3,5 мм: плоскость калибровки нельзя
поставить на разъём N/TNC/BNC/RP-SMA. Поэтому каждый такой переходник меряется в паре
с ответным по второму разъёму. Пара встаёт между концами SMA, результат делится на двоих.
Потери и задержка получаются точно, КСВН — оценка сверху. ERP пометит такие данные «ориентировочно».

| Пара (по разъёму X роды ответные) | Концы тракта |
|---|---|
| SN-321 + SN-322, ST-321 + ST-322, SB-321 + SB-322 (SMA розетка с обеих сторон пары) | вилка / вилка |
| SN-311 + SN-312, ST-311 + ST-312, SB-311 + SB-312 (SMA вилка с обеих сторон) | розетка / розетка |
| S-A311 + S-A322, S-A321 + …, S-AA* — по ответным родам RP-SMA | по стороне SMA |

Файл пары: `СИ.0NN+СИ.0MM.s2p`. Если у набора N-тип (Arinst) найдутся коэффициенты мер в паспорте —
переходники SMA–N можно будет мерить точно (калибровка порта 2 на плоскости N).

### Шаг 3. Переходники без SMA (N–N, TNC–N, BNC–N, TNC–BNC, TNC–TNC, BNC–BNC)

Встают между двумя уже охарактеризованными переходниками SMA–X из шага 2. Их вклад S2VNA вычитает по `.s2p`,
и остаётся сам переходник. Тоже «ориентировочно».

## Что сохраняется в ERP

- Файл `.s2p` в карточку переходника (вид «Характеризация»).
- Сводка: макс. КСВН каждой стороны по диапазонам, потери, электрическая длина (задержка), годен до f (где КСВН ≤ порога),
  дата и чем калибровали.
- Предварительный порог годности (уточнить по первым данным): SMA ≤ 1,15 до 6 ГГц и ≤ 1,25 до 18 ГГц; N/TNC ≤ 1,2 до 6 ГГц;
  BNC ≤ 1,2 до 2 ГГц. Хуже — «не для измерительного тракта».
- Перепроверка — раз в 6 месяцев или после 500 подключений; ERP напомнит, как о поверке.

## Время

Около 2 минут на переходник с подключением и сохранением. 84 шт. + пары — примерно 3–4 часа,
плюс по одной калибровке на каждую комбинацию родов концов (4–5 калибровок).

## Пока мастер в ERP не готов

Замеры можно делать уже сейчас вручную в S2VNA и складывать файлы `СИ.0NN.s2p` в папку `C:\VNA\переходники`.
Claude загрузит их в карточки и посчитает сводки скриптом.
