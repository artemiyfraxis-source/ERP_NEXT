# План РВ: шаги, которые делаем периодически

23.10.2026 · владелец: «составь план на РВ, будем делать периодически». Почему и что требуют нормы —
[README.md](README.md). Здесь — порядок работ: каждый шаг — один PR (одна сессия), полезен сам по себе и не ломает
текущую работу склада, приёмки и закупок. Берём следующий невыполненный шаг сверху; отметку ставим в этом файле.

Правила для всех шагов:
- связь между документами — внешний ключ (FK) на запись, а не совпадение номера текстом;
- новые таблицы сразу с ограничениями (NOT NULL, CHECK, UNIQUE, FK RESTRICT) и журналом изменений;
- старые записи не переписываем без миграции с репетицией на копии прода; где связать автоматически нельзя —
  оставляем пустую ссылку и показываем «не связано», а не угадываем.

## Этап 1. Связи поставки

- [ ] **1.1 Поставка → поставщик.** Ссылка «Прихода» на карточку контрагента (вместе с карточками контрагентов в
  справочниках — запрос владельца). Текст поставщика остаётся как напечатан в УПД.
- [ ] **1.2 Поставка → счёт закупки.** При вводе № счёта — подбор счёта из закупок этого поставщика, ссылка на него;
  у партии видно «по счёту № … (заказ …)».
- [ ] **1.3 Поставка → УПД из реестра (ЭДО).** Если тот же УПД пришёл по ЭДО — ссылка на него, скан и XML рядом.
- [ ] **1.4 Поставка → проект.** Назначение строки = проект из справочника проектов (ссылка), а не свободный текст.

## Этап 2. Входной контроль для «Поставки»

- [ ] **2.1 Признак «РВ» у проекта** (и у назначения строки поставки).
- [ ] **2.2 Партия РВ-проекта — в карантин.** Принятая для РВ-проекта партия не выдаётся до решения ВК.
- [ ] **2.3 Акт ВК на партию** (по образцу «Приёмки»: объём контроля, результат, контролёр, дата, протокол-файл);
  ссылка партия → акт.

## Этап 3. Документы партии

- [ ] **3.1 Файлы у партии:** сертификат, паспорт/этикетка изготовителя, протоколы — загрузка и просмотр в карточке
  партии (хранилище файлов как у сканов УПД).
- [ ] **3.2 Дата изготовления партии** и срок хранения (поле + этикетка).
- [ ] **3.3 Допуск ЭКБ:** признак на артикуле («перечень МОП» / «импорт по решению № …»), проверка спецификации и ТК
  перед запуском РВ-проекта.

## Этап 4. Партия → изделие

- [ ] **4.1 Включить прослеживаемость** (скрыта с PR #57): какие ГРН ушли в какое задание и изделие.
- [ ] **4.2 Заводские номера изделий** РВ-проекта и привязка выданных партий к номеру.

## Этап 5. ГОЗ

- [ ] **5.1 ИГК** на проекте, заказе поставщику, счёте и платеже.
- [ ] **5.2 Обособление:** резерв и выдача партий, купленных под ИГК, только в проекты этого ИГК.
- [ ] **5.3 Затраты по ИГК:** материалы по цене закупки, трудоёмкость по сессиям работы — отчёт.

## Этап 6. ОТК и военная приёмка

- [ ] **6.1 Роль «ВП»:** чтение дела проекта, отметки приёмки.
- [ ] **6.2 Предъявление ОТК → ВП**, результаты, извещения, возвраты; протоколы испытаний к изделию.
- [ ] **6.3 Паспорт / формуляр изделия** по ГОСТ 2.610 из данных производства.
- [ ] **6.4 Выпуски КД с литерой и извещениями** (по образцу выпусков ТД).

## Этап 7. Дело проекта

- [ ] **7.1 «Собрать свод»:** опись + PDF всех документов проекта по партиям и изделиям.
- [ ] **7.2 Неизменяемость после приёмки ВП:** правка принятых записей только через извещение.

## Перед первым РВ-проектом

- [ ] Сверить номера и редакции норм из README в ФГИС «Стандарт» / Консультанте.
- [ ] Узнать у заказчика и ВП состав сдаточной документации (ПС или ФО, на изделие или партию).
- [ ] Решить, нужна ли выгрузка затрат по ИГК в бухгалтерию (1С).
