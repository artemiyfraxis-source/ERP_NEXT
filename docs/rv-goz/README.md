# РВ и ГОЗ: свод документов по проекту и что нужно ERP

23.10.2026 · план «на будущее» (владелец: «пока просто держать в голове, реализовывать долго»)

На проекте РВ (с военной приёмкой) или ГОЗ ERP должна одной кнопкой собрать **дело проекта**: по каждому
комплектующему — откуда пришло и с какими документами, по каждому изделию — как изготовлено, проверено и принято.
Сегодня эти данные частью есть, но лежат в разных местах и связаны текстом номеров, а не прямыми ссылками. Ниже —
что требуют нормы, что уже есть, чего не хватает и в каком порядке строить. Ближайшие изменения склада, приёмки и
закупок закладываем так, чтобы к этому не переделывать.

## 1. Нормативная база

Список составлен по памяти, без сверки с источниками: номера, редакции и статус каждой нормы — **проверить в ФГИС
«Стандарт» и Консультанте** перед первым проектом.

| Норма | О чём | Что требует от ERP |
| --- | --- | --- |
| ГОСТ РВ 0015-002 (СМК для ВВСТ) | Система качества поставщика ВВСТ: документы и записи, идентификация и прослеживаемость, несоответствия, работа с ВП | Записи неизменяемые и связанные: изделие → операции → партии комплектующих → поставка |
| ГОСТ РВ 0015-308 (входной контроль) | ВК покупных изделий: проверка сопроводительных документов, объём контроля, журнал и акты, изоляция брака | Протокол/акт ВК на каждую партию, карантин, запрет выдачи до ВК |
| ГОСТ РВ 15.307 (испытания и приёмка серийных изделий) | Предъявительские испытания ОТК, приёмо-сдаточные и периодические с ВП, извещения, возвраты | Статусы предъявления ОТК → ВП, протоколы испытаний, отметка ВП на партии изделий |
| ЕСКД ГОСТ 2.601 / 2.610 | Эксплуатационные документы: паспорт (ПС), формуляр (ФО), этикетка (ЭТ) | Паспорт/формуляр на изделие или партию с заводскими номерами |
| ЕСТД (ГОСТ Р 3.102-2024 и др.) | МК, ОК, ВМ, ТЛ, литеры, извещения об изменении | Уже есть: выпуски ТД (`td_issues`), см. память `rv-td-base` |
| Положение о военных представительствах МО РФ (ПП РФ № 804) | Права ВП: контроль качества, приёмка, доступ к документации | Роль «ВП»: чтение дела проекта, отметки приёмки |
| Перечни ЭКБ, разрешённой к применению (МОП); порядок применения импортной ЭКБ | Отечественная ЭКБ — из перечня, импортная — по решению заказчика | Признак «разрешена / решение № …» на артикуле, проверка спецификации |
| 275-ФЗ «О государственном оборонном заказе» | ИГК, отдельный счёт в уполномоченном банке на каждый контракт, раздельный учёт | ИГК на проекте, заказе поставщику и платеже; затраты по ИГК |
| Правила раздельного учёта по ГОЗ (ПП РФ № 47) | Затраты и результаты — отдельно по каждому контракту | Материалы, труд, оборудование — с разнесением на контракт |
| Регулирование цен по ГОЗ (ПП РФ № 1465) | Калькуляция цены, обоснование затрат | Фактические цены закупки и нормы времени — источник для калькуляции |

## 2. Свод по комплектующему (на каждую партию ГРН)

| Документ / запись | Откуда | Есть в ERP сейчас |
| --- | --- | --- |
| Счёт поставщика (№, дата, ИГК для ГОЗ) | Закупка | Счета Kaiten в закупках; в «Поставке» — № и дата текстом |
| УПД (№, дата, строки, файл) | Поставщик / ЭДО / скан | Реестр УПД (ЭДО) в закупках; скан PDF в «Поставке» |
| Сертификат / паспорт / этикетка изготовителя | Поставщик | Поле «сертификат» у партии — текст, без файла |
| Дата изготовления, срок хранения/годности | Этикетка изготовителя | Срок годности у партии; даты изготовления нет |
| Признак допуска ЭКБ (перечень МОП / решение) | Справочник | Нет |
| Протокол и акт ВК, решение (годно / карантин / возврат) | Приёмка | Есть в «Приёмке» (строки, акты ВК, карантин) — только для закупок ERP, не для «Поставки» |
| ГРН, место хранения, остаток | Склад | Есть |
| Выдача: в какой проект, задание, изделие и сколько | Комплектация / производство | Списания и выдачи есть; связь «партия → конкретное изделие» неполная |

## 3. Свод по производству и изделию

| Документ / запись | Есть в ERP сейчас |
| --- | --- |
| Конструкторская документация (СБ, Э4, спецификация) с литерой | Чертежи по ЕСКД делаются, но не хранятся как выпуск с литерой и извещениями |
| ТД: МК, ОК, ВМ, ТЛ, комплект по ЕСТД | Есть: выпуски ТД, нормоконтроль, печать |
| Задание на производство, операции, исполнители, время | Есть (задания, сессии работы, сдача) |
| Использованные партии комплектующих на изделие/коробку | Частично (прослеживаемость скрыта, PR #57) |
| Контроль ОТК, брак, решения по несоответствиям | Есть (ОТК, брак цеха/ОТК) |
| Протоколы испытаний (КСВН и т. п.) | Есть для коаксиальных сборок (замеры ВАЦ, паспорт сборки) |
| Предъявление ВП, приёмка ВП, извещения | Нет |
| Паспорт / формуляр изделия с заводскими номерами | Паспорт кабельной сборки есть; общего ПС/ФО нет |
| Акт приёмки ГП, отгрузка, УПД покупателю | Есть (акты ГП, отгрузка) |

## 4. Требования ГОЗ к учёту

- **ИГК** (идентификатор госконтракта) на проекте и на всём, что идёт под контракт: заказ поставщику, счёт, платёж,
  поставка, партия.
- **Обособленные материалы:** партии, купленные под ГОЗ-контракт, не должны «уезжать» в другие проекты без
  оформления; резерв/выдача проверяют ИГК.
- **Затраты по контракту:** материалы по фактической цене закупки, трудоёмкость по фактическим сессиям работы,
  оборудование — для отчёта и калькуляции.
- **Отдельный счёт в банке** — бухгалтерия, не ERP; ERP хранит ИГК и номер платёжки в цепочке.

## 5. Чего не хватает

| Разрыв | Почему важно | Сложность |
| --- | --- | --- |
| Прямые связи: проект → счёт → УПД → ВК → ГРН → выдача → изделие (сейчас — совпадение номеров текстом) | Без них свод собирается руками | Средняя: новые FK + перенос имеющихся связей |
| «Поставка» не проходит ВК по ГОСТ РВ 0015-308 | Для РВ партия без акта ВК не может идти в производство | Средняя: связать «Поставку» с приёмкой/ВК |
| Файлы документов у партии (сертификаты, паспорта, этикетки изготовителя) | Свод — это файлы, а не только поля | Небольшая: хранилище файлов уже есть у сканов |
| Признак допуска ЭКБ и проверка спецификации | Импортная ЭКБ без решения — недопуск | Средняя |
| Дата изготовления партии | Сроки хранения, требования заказчика | Небольшая |
| ИГК и обособление партий под контракт | Требование 275-ФЗ | Средняя |
| Роль ВП, предъявление и приёмка ВП, извещения | Ядро РВ | Большая |
| Паспорт/формуляр изделия по ГОСТ 2.610 | Сдаточная документация | Средняя (шаблон + данные из производства) |
| Выпуски КД с литерой и извещениями | РВ требует учтённую КД | Средняя (по образцу выпусков ТД) |
| Сборка «дела проекта» (PDF-пакет + опись) | Конечный результат для ВП/заказчика | Средняя, когда есть связи выше |
| Неизменяемость записей (журнал правок, запрет удаления после приёмки) | Требование СМК | Небольшая для новых таблиц; аудит уже ведётся |

## 6. Как строить

Цепочка, которую должна держать база (каждая стрелка — внешний ключ, а не совпадение номера):

```
Проект (ИГК) ─┬─ Заказ поставщику ── Счёт ── Платёж
              │                        │
              │                        └── УПД (файл, строки) ── Поставка/приёмка
              │                                                     │
              │                                       Акт ВК ── Партия ГРН (+ файлы: сертификат, паспорт)
              │                                                     │
              └─ Изделие (зав. №) ── Задание ── Операции ── Выдача партий
                       │
                       ├── Контроль ОТК / испытания (протоколы)
                       ├── Предъявление ВП ── Приёмка ВП
                       └── Паспорт / формуляр ── Акт ГП ── Отгрузка (УПД покупателю)
```

Этапы — каждый полезен сам по себе:

1. **Связи и файлы партии.** FK «Поставка/приёмка → УПД → счёт → проект», файлы документов у партии, дата
   изготовления. Склад, приёмку и закупки, которые трогаем сейчас, делаем уже на этих связях.
2. **ВК для «Поставки».** Партия из «Поставки» на РВ-проекте сначала в карантин, акт ВК, потом выдача.
3. **Партия → изделие.** Включить прослеживаемость: какие ГРН ушли в какое изделие (зав. №).
4. **ИГК и обособление.** ИГК на проекте и закупке; резерв/выдача проверяют контракт; отчёт затрат по ИГК.
5. **Допуск ЭКБ.** Признак на артикуле, проверка спецификации/ТК перед запуском.
6. **ВП.** Роль, предъявление, приёмка, извещения; паспорт/формуляр по ГОСТ 2.610.
7. **Дело проекта.** Кнопка «Собрать свод»: опись + PDF всех документов по проекту, по партиям и изделиям.

## Открытые вопросы

- Какие заказчики и какие ВП будут на первых РВ-проектах — от этого зависит набор форм и испытаний.
- Требуются ли ПС/ФО на каждое изделие или на партию.
- Нужна ли интеграция с бухгалтерией (1С) для раздельного учёта затрат по ГОЗ или достаточно отчёта ERP.
