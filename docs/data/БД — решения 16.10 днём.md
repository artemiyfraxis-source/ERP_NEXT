## 3. BNC-C58P и N-C58P (RUICHI) — L2 исправлена

L2 была записана приростом, поэтому получалось L2 < L1. Длины L1–L3 отсчитываются от торца нарастающим итогом,
отсюда L2 = L1 + прирост. BNC-C58P: 5 / 2,5 / 12 → 5 / **7,5** / 12. N-C58P: 3,5 / 3 / 11 → 3,5 / **6,5** / 11.
Оплётка у обоих выходит 4,5 мм, как у обжимных BNC/N. Чертежа RUICHI нет — решено агентом, проверить.
