## 4. Проверка «Материала жилы» (ничего не перезаписано)
- КСПВГ «медь» — верно: у Паритета жила медная многопроволочная, 4 класс (см. «Жила» строк и карточки paritet.su).
- МГШВ «медь лужёная» — верно: по ТУ 16-505.437-82 жила скручена из медных лужёных проволок
  (https://s.electrical.ru/files/products/99/99bf678c48fcee3c5f76bb7cc41e439a_5f71ef21a47f0.pdf).
- UL1007 / UL1061 / UL1571 «медь лужёная» — это допущение, а не требование UL. Стиль AWM допускает и луженую, и голую
  медь: «Solid or stranded, tinned or bare copper conductor»
  (https://p.globalsources.com/IMAGES/PDT/SPEC/758/K1237756758.pdf, UL1571). Каталожные провода этих стилей обычно
  лужёные, а изготовитель у строк не указан, поэтому ячейки оставлены как есть. Если закупленный провод голый,
  поменяйте значение на «медь».

## 5. AGR2 Core 0,3
0,3 мм² есть в ряду серии на карточке товара владельца: «… Silicone Wire … AGR2 Core 0.3 0.5 0.75 1 1.5 2.5mm2 …»
(https://www.aliexpress.com/item/32906320925.html). В «Сечения AWG ↔ мм²» добавлена строка 0,3 мм² без AWG — так же,
как 0,07 / 0,1 / 0,14 (`import_rows("wire-gauges")`). Затем `structure_hookups` построил структуру «AGR2 Core 0,3».
До запуска скрипт проверил, что запуск затронет только этот провод. Ближайший AWG 22 соответствует 0,35 мм²,
поэтому AWG не ставился.
