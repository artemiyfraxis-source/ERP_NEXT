# Нормы КСВН коаксиальных переходов: ГОСТ / ОСТ / IEC против MIL — 18.11.2026

Вопрос владельца: «почему только MIL?» Сейчас запасная норма для переходов без данных изготовителя берётся из
MIL-PRF-55339, для соединителей — из MIL-PRF-39012 (`backend/data/rf-norms.json`, исследование
[norms-coax-testing-2026-11-18.md](norms-coax-testing-2026-11-18.md), PR #912). Здесь проверено, есть ли числовые
нормы КСВН и вносимых потерь в отечественных и международных документах на серии SMA, 3,5 мм, N, TNC и BNC.

Правило записи: у каждого числа есть первоисточник из списка в конце ([1], [2] …). Если текст не открыт, это сказано
прямо (**не проверено**). F и f — частота в ГГц.

## Коротко

- **ГОСТ, ГОСТ Р, ОСТ.** Открытого документа с числовой нормой КСВН на переходы или соединители SMA, N, TNC, BNC и
  3,5 мм нет. ГОСТ 20265-83 и ГОСТ 13317-89 задают только присоединительные размеры. ГОСТ РВ 51914-2002 закрыт.
  Отраслевые ОСТ в открытом доступе не найдены. В отечественной практике КСВН задаёт ТУ на конкретное изделие.
- **IEC.** Секционные спецификации IEC 61169-x платные. Исключение — IEC 61169-8 (BNC): его идентичный перевод
  IS 5054 (Part 8):2013 бесплатно лежит в Internet Archive. Норма BNC: коэффициент отражения ≤ 0,13 для прямых и
  ≤ 0,15 для угловых до 4 ГГц, то есть КСВН ≤ 1,30 и ≤ 1,35.
- **ESCC 3402** (Европейское космическое агентство) — бесплатный открытый текст с формулами КСВН и потерь именно
  для **переходов** SMA (3402/003) и TNC (3402/010). Это вторая, не американская открытая база норм.
- **Порядок норм, который можно принять сейчас:** изготовитель → ГОСТ/ОСТ/ТУ (пока пусто) → IEC (BNC) →
  ESCC (SMA, TNC) → MIL (межсерийные, N–N). Числа — в разделе 4.

## 2. IEC и национальные переводы

| Документ | Серия | КСВН / потери | Статус и доступ |
|---|---|---|---|
| **IEC 61169-8:2007 = IS 5054 (Part 8):2013** (идентичный перевод, «without deviations») [10] | BNC, 50 Ом | Табл. 9: частотный диапазон «Up to 4 GHz» для соединителей класса 2. Коэффициент отражения: **≤ 0,13 для прямых, ≤ 0,15 для угловых**; для приборных и PCB-исполнений — «as specified in the DS». В п. 7.2 разрешено применение выше 3 ГГц, если допустим коэффициент отражения больше 0,1 (прямые) и 0,13 (угловые). Сноска a: значения относятся к базовым соединителям и зависят от кабеля | IEC 61169-8:2007 ed1 действует, дата стабильности 2028. **IS-перевод бесплатный** |
| IEC 61169-15:2021 | SMA | В табл. «Ratings and characteristics» есть рекомендуемые значения. Чисел нет | Платный. Пробная выдержка содержит только оглавление и область применения. **Не проверено** |
| IEC 61169-16:2006 | N (50 и 75 Ом) | То же | Платный, ed1 действует (стабильность 2028). **Не проверено** |
| IEC 61169-17:2022 (заменил IEC 60169-17:1980) | TNC | То же | Платный. **Не проверено** |
| IEC 61169-23:2025 (заменил IEC 60169-23) | 3,5 мм; стыкуется с SMA и 2,92 мм | В области применения: «low reflection to 34 GHz». Табл. 7 «Rating and characteristics» в выдержку не входит [11] | Платный. **Не проверено** |
| IEC 61169-1 (общие требования), IS 5054-1-2 (= IEC 169-1-2, метод измерения коэффициента отражения) [12] | Все | Только методы. Пределы задаёт DS | IS-перевод бесплатный |
| IEC 60966-1 / -2-1 = IS 14686-1:2006 / IS 14686-2-1:1999 [13] | Кабельные сборки | Только методы. По п. 9.1: «return loss (A_r) is preferred», пределы — в частной спецификации | IS-переводы бесплатные |
| IEEE 287.1-2021 | Прецизионные 7 мм, N, 3,5 мм, 2,92 мм и др. | Минимальные требования по классам (instrument / metrology) | Платный. **Не проверено**; идёт пересмотр (PAR 2026) |
| GB/T 11313.15-2018 (SMA), GB/T 11313.16-2015 (N) | — | — | Китайские, неэквивалентные (NEQ) IEC. Пробная выдержка обрывается до табл. 4.2. **Не проверено** |

Также бесплатно, но **не IEC**: IS 11075 (Part 2/Sec 1):1984, BNC, составлен по индийскому военному JSS 52401 [14].
КСВН ≤ 1,15 на DC–4 ГГц для профессионального класса и ≤ 1,3 для бытового; потери 0,2 дБ на 3 ГГц. Угловая вилка
(Part 2/Sec 3): КСВН ≤ 1,3 на 0,5–4 ГГц, потери 0,3 дБ на 3 ГГц. Для N и SMA в архиве есть только Part 1 (программы
испытаний IS 12380-1 и IS 12419-1) без чисел.

## 3. ESCC 3402 — открытые нормы именно на переходы

ESCC — система спецификаций Европейского космического агентства. Тексты бесплатные: разрешено некоммерческое
копирование целиком. По методике (ESCC 3402, п. 9.16) значения нормируются на всей полосе от 0 ГГц.

| Спецификация | Переход | Полоса | КСВН, не более | Потери, дБ, не более |
|---|---|---|---|---|
| **3402/003 Issue 6 (06.2025)** [15], варианты 01–04, 09–14 | SMA прямые: вилка–вилка, вилка–розетка, розетка–розетка, проходной | 0–18 ГГц | **1,1 + 0,008·f** | **0,02 + 0,06·√f** |
| то же, вариант 05 | SMA угловой вилка–розетка | 0–18 ГГц | 1,05 + 0,01·f | 0,02 + 0,06·√f |
| то же, вариант 15 | SMA угловой вилка–розетка, высокотемпературный | 0–18 ГГц | 1,1 + 0,006·f | 0,02 + 0,06·√f |
| то же, вариант 07 | SMA герметичный розетка–розетка | 0–18 ГГц | 1,1 + 0,015·f | 0,02 + 0,15·√f |
| **3402/010 Issue 2 (04.2014)** [16], вариант 02 | TNC вилка–розетка | 0–18 ГГц | **1,1 + 0,005·f** | **0,07·√f** |
| то же, варианты 03, 04 | TNC розетка–розетка, проходной | 0–18 ГГц | **1,15 + 0,003·f** | 0,07·√f |
| то же, вариант 01 | TNC вилка–вилка | 0–18 ГГц | 1,1 + 0,005·f до 12,4 ГГц; «1,16 + 0,008·f up to 18 GHz»¹ | 0,07·√f |

¹ Формула второго участка взята дословно. Она даёт скачок на 12,4 ГГц (1,162 → 1,259); возможно, имелось в виду
(f − 12,4). **Не проверено.** Более новый выпуск 3402/010 не искался.

Для N, BNC и 3,5 мм ESCC переходов не задаёт. 3402/023 — это SMA 2.9 (2,92 мм), 3402/006 — SSMA.

## 4. Рекомендация: порядок норм и числа

**Порядок** (первая применимая норма побеждает; в паспорте пишется её источник):

1. **Изготовитель** — паспорт, РЭ или ТУ на конкретный артикул (Планар ADP1A, Микран ЖНКУ.468562.002 ТУ и т. п.).
2. **ГОСТ / ГОСТ Р / ОСТ / ТУ** с числовой нормой на тип. Сейчас пусто: открытых документов нет (раздел 1).
   Уровень стоит оставить в схеме, чтобы ТУ поставщика можно было добавить без кода.
3. **IEC** — когда текст доступен. Сейчас это только BNC по IEC 61169-8.
4. **ESCC 3402** — переходы SMA–SMA и TNC–TNC.
5. **MIL-PRF-55339 / 39012** — межсерийные переходы и N–N.

Оговорка к пунктам 3–5. IEC и ESCC — тоже иностранные документы. Их плюс перед MIL: IEC — международный стандарт,
который ГОСТ обычно переводит; ESCC — гражданская европейская система с открытым текстом и нормой на тот же класс
изделий. Строже ли норма, зависит от серии: для SMA вилка–розетка MIL /55 строже ESCC (1,05 + 0,005·f против
1,1 + 0,008·f).

**Что можно принять сейчас** (КСВН, не более, на ступенях этикетки):

| Переход | Источник | 1 ГГц | 3 ГГц | 6 ГГц | 12 ГГц | 18 ГГц | Потери, дБ, на 1 / 6 / 18 ГГц |
|---|---|---|---|---|---|---|---|
| SMA–SMA, прямой, любые роды | ESCC 3402/003 | 1,108 | 1,124 | 1,148 | 1,196 | 1,244 | 0,08 / 0,167 / 0,275 |
| SMA–SMA, угловой | ESCC 3402/003, вар. 05 | 1,06 | 1,08 | 1,11 | 1,17 | 1,23 | 0,08 / 0,167 / 0,275 |
| для сравнения: SMA вилка–розетка | MIL-PRF-55339/55 (сейчас в rf-norms.json) | 1,055 | 1,065 | 1,08 | 1,11 | 1,14 | √F-формула MIL |
| TNC вилка–розетка | ESCC 3402/010 | 1,105 | 1,115 | 1,13 | 1,16 | 1,19 | 0,07 / 0,171 / 0,297 |
| TNC розетка–розетка | ESCC 3402/010 | 1,153 | 1,159 | 1,168 | 1,186 | 1,204 | 0,07 / 0,171 / 0,297 |
| BNC–BNC, прямой | IEC 61169-8, табл. 9 (Γ ≤ 0,13) | 1,30 | 1,30 | — (до 4 ГГц) | — | — | не задано |
| BNC, угловой | IEC 61169-8, табл. 9 (Γ ≤ 0,15) | 1,35 | 1,35 | — | — | — | не задано |
| N–N, SMA–N, SMA–TNC, BNC–N, SMA–BNC | MIL-PRF-55339 (без изменений) | см. norms-coax-testing, раздел 2 | | | | | |
| 3,5 мм – 3,5 мм и 3,5 мм – N | только изготовитель (Планар ADP1A, Микран). IEC 61169-23 платный | | | | | | |

Замечания:
- BNC по IEC (1,30) мягче, чем MIL /13B (1,25 для негерметичного проходного). Порог 1,30 совпадает с текущим
  `shop_requirement.vswr_max`. Теперь у него есть международный источник, но только для BNC.
- Норма IEC 61169-8 относится к соединителю, а не к переходу. Переход BNC–BNC — это два таких интерфейса, поэтому
  1,30 — это норма на тип, а не расчёт Γ1 + Γ2. Это принятое допущение, отдельной нормы IEC на переходы BNC нет.
- Чтобы закрыть SMA, N, TNC и 3,5 мм по IEC, нужно купить IEC 61169-15, -16, -17 и -23 (webstore.iec.ch) и
  переписать их таблицы «Ratings and characteristics» в `rf-norms.json`.

## 5. Не найдено или не проверено

- Числа IEC 61169-15/-16/-17/-23, IEC 60966-2-x и IEEE 287.1 — тексты платные.
- ОСТ 4 и ОСТ 11 на соединители и переходы, «ГОСТ 20465-85», ГОСТ РВ 51914-2002 — открытого текста нет.
- Действует ли ГОСТ 20265-83 и ГОСТ 13317-89, по ФГИС Росстандарта не проверялось, только по агрегаторам.
- Последний выпуск ESCC 3402/010 (взят Issue 2, 2014). Для 3402/003 взят Issue 6 (06.2025).
- MIL-листы на переходы 3,5 мм не искались.
