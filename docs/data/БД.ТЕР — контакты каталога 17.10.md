# БД.ТЕР — 15 контактов каталога, которых нет в БД.ТЕР, 17.10.2026

Источник списка — «Каталог — контакты не в БД.ТЕР 17.10.csv» (ветка `series-card-terminals-1017`). Результат —
«БД.ТЕР — контакты каталога 17.10.csv»: одна строка на артикул, столбцы — ключи схемы БД.ТЕР и «Источник высоты обжима».
**В базу ничего не записано.** Все значения — из документов производителя (номер документа и ссылка в каждой строке).
Пустая ячейка — производитель значения не даёт или документ недоступен из РФ; причина — ниже.

Формат как в журналах 16.10–17.10: `a ± t` записано диапазоном `a−t – a+t`, запятая, тире «–», AWG от тонкого к толстому;
отрыв — в Н; дюймы/фунты (Samtec) пересчитаны в мм/Н. Пустые мм² там, где производитель даёт только AWG (и наоборот):
пересчёт по таблице не делался, это не данные производителя.

Скопировано из строк той же серии (не из документов): только когда контакт тот же по чертежу.
- T-DS1071-01-SC000 / SC800: `terSeries`, `terComponent`, `terStep`, `terLPlus` = 5 и `terApplicator` = «S17/M17/A15»
  (это коды аппликаторов цеха, у Connfly своего инструмента нет) — из T-DS1071-01-SC600, тот же чертёж T-DS1071-01-SCX00.
- DF19A-3032SCFA / -36SCFA: `terLPlus` 4, `terLMinus` 2,1 — из DF19A-2830SCFA; размеры контакта на трёх чертежах Hirose одинаковы.
- SQS-A03GI-P-P: `terStep` 2 и `terLPlus` 5 — из SQS-A03GF-P-P (тот же контакт, другое покрытие).

корпуса GHDR-10V-S-1 (F) … GHDR-40V-S-1 (F), шаг 1,25; ток 1,25 A (26 AWG) / 1,0 (28) / 0,8 (30).

- **-003T**: 0,032–0,08 мм², 32–28 AWG, Ø 0,4–0,8; APLMK SGHD003-02. В Tooling Guide номера нет → пусто: высота, отрыв,

### JST EL — SLM-42T-P1.3E (штырь), SLF-42T-P1.3E (гнездо)
Каталог JST EL (`eEL.pdf`) + Tooling Guide. Контакт на **два провода**: 0,3+0,3 – 0,5+0,5 мм², AWG 22+22 – 20+20,
Ø 1,7+1,7 – 2,0+2,0. В ячейки AWG/мм²/Ø записан диапазон на один провод (22–20, 0,3–0,5, 1,7–2,0), в высоте обжима —

для 22+20 — нет. Материал по каталогу — фосфористая бронза/олово у обоих (латунь — только по запросу).
- **Расхождение с базой:** по каталогу JST «Receptacle housing (for pin contact)» — ELR, «Plug housing (for socket contact)» — ELP.
  В CSV: SLM → ELR, SLF → ELP. В БД у SLM-01T/-41T стоит ELP, у SLF — ELR, то есть наоборот — стоит проверить.
- Пусто: высота по изоляции (JST не даёт), L+/L− (обжимная часть другая, чем у -01T/-41T — не копировал).
