  `sto_section` по новому файлу); RJ остаётся в 4.7 (заголовок дополнен «оконцовка вилок RJ»). Строка docstring
  про «4.4.5 пайка пинов» — можно поправить на «контактов» (заголовок 4.4.5 переименован).
- `frontend/src/tdTypes.ts`: `StoRow.basis: string`, `StoSection.norms?: {doc; clauses; subject}[]`,
  `Sto.changes_detail?`, `Sto.code_map?`.
- `frontend/src/stoPrint.ts`: 7-я графа «Основание» и строка «Технические требования — по …» из `norms` под
  заголовком раздела; при желании — приложение «Лист изменений, подробно» из `changes_detail`.
- `frontend/src/tdPrintSheets.test.ts`: ожидается 236 кодов → 320. Строка «Первая редакция» в листе изменений
  сохранена.
- Печать норм в МК/ОК («Технические требования — по …») — новая функция комплекта ТД, кода для неё пока нет.
- Шаблоны D1 пишут «изоляция может касаться припоя» (ГОСТ Р МЭК 61191-4-2019, п. 5.4.7) рядом с допуском 0,2 мм; СТО
  4.4.2.8 берёт более строгую отечественную норму ГОСТ 23587-96, п. 6.1.4 (не менее 0,2 мм). Фразу в картах убрать.

## Вопросы владельцу (блокеры)

1. ГОСТ 23587-96, п. 6.2.6 разрешает кабельные наконечники с обжимом только для проводов сечением более 4 мм², а
   п. 6.2.8 требует для жил до 0,5 мм² под зажим трубчатый наконечник с пайкой. Для заказов ГОСТ РВ: КД разрешает
   обжим НКИ/НВИ/РПИ и НШВИ на меньших сечениях (по ГОСТ Р 72182.2-2025), или эти операции на РВ не применяем?
2. Класс конечного изделия A/B/C (ГОСТ Р 72182.2-2025, п. 5.1.2–5.1.4) задаёт КД; если в КД нет — по умолчанию C
   для ГОСТ РВ? От этого зависит допуск оборванных проволок (4.2.2).
3. ПМЛ: в резке (CUT_ПМЛ) это плетёнка медная лужёная, в маркировке (INS_ПМЛ) — маркер? Строка 4.1.21 написана под
   плетёнку.
4. Обжим медной лентой (4.3.40–4.3.44): это сросток жил или бандаж экрана? Строки написаны нейтрально («бандаж»);
   для экрана ГОСТ 23585-79, п. 12 медную ленту не называет.
5. УЗ-сварка, плазма, литьё: есть ли ТИ с режимами и минимальным усилием отрыва? 11 строк 4.11 опираются на ТИ;
   без ТИ их критерии нечем проверить.
