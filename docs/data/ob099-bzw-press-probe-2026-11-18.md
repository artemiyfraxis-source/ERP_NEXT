## Карта ПЛК из BZW2.5.exe (строки .NET, без запуска)
Формат в коде: `адрес;тип;значение`, тип 0 = Int16, 1 = Int32 (DT), 3 = бит, 4 = чтение блока длины N, 5 = строка.

Циклический опрос HMI (`;4;` — блоки чтения): `D5005×80`, `D5100×45`, `H60×2`, `W80×5`, `W61×9`, `W101×8`,
`D5500/D5510/D5520/D5530/D5540 ×10` (строки), `D7000×8000` (таблица обучения сервопресса — файлы
`2.5T/4T/8T-…-示教数据.txt` в папке программы).

| Адрес | Значение | Уверенность |
|---|---|---|
| D5500 / D5510 / D5520 / D5530 (строки по 10 слов) | модель изделия / провод / клемма / аппликатор текущего рецепта | высокая (код загрузки рецепта) |
| D5540 (строка) | номер оборудования | высокая |
| D5006 | высота обжима, мм (столбец «压接高度» в списке рецептов) | высокая |
| D5005 | номер экрана/режима, HMI пишет 2…17 при переходах | высокая |
| H60.07 | вход/выход из режима «Работа» (进入运行/退出运行) | высокая |
| DT5104 / DT5106 | «批量 / 总量» — счётчик партии / общий счётчик (экран «Производство») | средняя |
| DT5100 / DT5102 | рядом с ними на экране «Производство», сброс `D5100;1;`, `D5102;1;` | низкая |
| DT5108 / DT5110 | ресурс / наработка ножа обжима (Управление инструментом) | средняя |
| DT5112 / DT5114 | ресурс / наработка ножа отсечки отходов | средняя |
| D5010 | скорость предобжима | средняя |
| D5032 | допуск высоты ±мм | средняя |
| DT5142 | значение нижней точки (калибровка) | средняя |
| D5008, D5012, D5013, D5021, D5036, DT5118, DT5124, D5050–D5052 | параметры рецепта (скорость обжима %, ручные скорости, удержание…) — привязка не подтверждена | низкая |
| W6000–W6008, W6011, H6014, H61.01–H61.14 | флаги опций (подача, отсечка, контроль качества, ограждение, кожух, предобжим…) | низкая |
| X0–X11 / Y0–Y7 | входы: энкодер A/B, педаль НО/НЗ, световая завеса, ноль серво, авария давления, обучение, авария серво, кожух; выходы: импульс/направление серво, обучение усилия, отсечка, пневмоподача, авария, предобжим, **Y7 «цикл завершён»** | высокая (подписи) |

Подтверждать привязку «средняя/низкая» — только чтением FINS (команда 0101) при открытом экране, с разных сторон
(снять блок → изменить параметр в HMI оператором → снять блок → diff). Писать в ПЛК до подтверждения карты — нельзя.
