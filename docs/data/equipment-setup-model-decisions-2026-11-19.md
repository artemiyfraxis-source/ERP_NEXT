# Модель наладки БД.ОБ — решения по открытым вопросам (19.11.2026)

Владелец 19.11: проверку CSV не ждать, открытые вопросы решает главная сессия. Решения ниже приняты по умолчаниям
самого предложения (`equipment-setup-model-proposal-2026-11-18.csv`, PR #946). В CSV колонка `reviewed` во всех
408 строках: «решение Claude 19.11 (владелец: не ждать)» — сид принимает такую отметку наравне с «да».

| № | Вопрос | Решение |
|---|---|---|
| 1 | ОБ.001 / ОБ.002 (настольная и ИК термоусадка): «простая» или «нет»? | «простая» — температура и время по трубке (эталон по типу трубки из ЭТК), как в предложении. Ручные фены ОБ.070.* — «нет». |
| 2 | ОБ.101 / ОБ.102 — «онлайн», если подключён только принтер Godex? | Да, «онлайн» — как в предложении: их принтер Godex на агенте печати (ПК SK-20250818JOKI) — значит станок досягаем из ERP. Сам станок без подключения; в CSV это сказано в колонке `agent`. Признак не хранится, его считает `connections()` по привязке маркировки. |
| 3 | ОБ.009 и ОБ.092 — без модели, что это за устройства? | Как в предложении: ОБ.009 — устройство зачистки плоского кабеля, «простая», длина зачистки из ЭТК; ОБ.092 — флажковый маркиратор, «простая», размер флажка из ЭТК. Модель оборудования в БД.ОБ у обоих есть (`model_id` в CSV), пустой только артикул. |
| 4 | ОБ.024.* (прессы MHF под один разъём) и ОБ.060.* (паяльные ванны) — «нет»? ОБ.093 — «полная»? | ОБ.024.1–4 и ОБ.060.1–2 — «нет» (выделенный пресс под один разъём; ванна с постоянной температурой по припою). ОБ.093 (BZW-20TS) — «полная»: матрица, сечение наконечника, программа пресса. |
| 5 | Кого уведомлять о правке ЭТК наладчиком? | Тех, кто уже получает уведомления о правках ЭТК: аудитория «Технолог, владелец, безопасность» (`technologist`). Уже так сделано в `workflows/machine_writes_api.py` (правка из карточки станка → новая ревизия ЭТК с причиной «правка наладчика: …», уведомление «Правка ЭТК наладчиком», вид `etk_setup_correction`) — не согласование, только уведомление. Кода не нужно. |
| 6 | Поправка станка — нужна ли ещё на контакт? | Как в предложении: поправка на параметр — общая для станка или на один провод (свой провод важнее общего). На контакт отдельной поправки нет: размеры по контакту идут из справочника контактов и эталона «станок + контакт». Схема не меняется. |
| 7 | Рецепты ОБ.019 (`equipment_setup_recipe_versions`, на проде 0 строк) перевести на эталоны и закрыть старую таблицу? | В этом срезе не решается: на сид не влияет, данных в старой таблице нет. Вернуться в срезе записи эталонов с экрана наладки. |

Сид: `python -m app.workflows.equipment_setup_model --seed <csv>` (по умолчанию только показывает; `--apply` пишет).
Ключ — модель оборудования / единица (ОБ) и `param_key`; повторный запуск ничего не меняет. Каждая созданная или
изменённая модель / переопределение — запись в журнале (`audit_events`: `equipment_setup.model_seeded`,
`equipment_setup.unit_override_seeded`, автор «Модель наладки (CSV владельца)»). Откат — по этим записям журнала:
таблицы `equipment_setup_models`, `equipment_setup_model_parameters`, `equipment_setup_unit_overrides`,
`equipment_setup_unit_parameters` до сида были пустыми.
