## Как достали документы (новое к 17.10 днём)

- **Web Archive из браузера, точный CDX.** Поиск по префиксу DDEController с regex-фильтром (и из раннера GitHub, и из браузера)
  упирается в 503/504. Работает точный запрос: даташит TE `web/2024id_/te.com/en/product-<PN>.datasheet.pdf` → в нём ссылки
  `DDEController?Action=showdoc&DocId=<тип>%7F<номер>%7F<ред.>%7Fpdf%7FEnglish%7F<файл>%7F<PN>` → CDX `url=<эта ссылка>`
  (без matchType) отдаёт снимок за секунду → PDF через `fetch` в странице web.archive.org, base64 в файл
  (`evaluate_script` с `filePath`). Локальный curl к архиву — 429 после пары запросов.
- **Molex** — так же: `molex.com/content/dam/molex/molex-dot-com/products/automated/en-us/salesdrawingpdf/<3>/<серия>/<PN>_sd.pdf`
  и старые `molex.com/pdm_docs/sd/<PN>_sd.pdf`; CDX по префиксу каталога серии работает.
- **JAE** — products.jae.com открыт из РФ; запись изделия: `products.jae.com/graphql/execute.json/jae/get-product-by-url;pathPrefix=/content/dam/jae/connectors/cf-master/global/en/;productUrl=<pn в нижнем регистре>`
  → `drawingSjArchive._path` (PDF чертежа), `specificationJacsArchive`.
- **Hirose** — `hirose.com/api/v1/series/<серия>/products`, `…/products/<CL>/documents` и `…/documents/<тип>/content?lang=EN`.
- Раннер GitHub (`tools-fetch-docs`) — прямые id_-ссылки архива отдаёт, CDX с regex — 503 и таймауты; в workflow добавлены повторы
  и пауза.
