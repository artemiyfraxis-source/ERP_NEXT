# КОАКС — пробелы БД

Проверено 11.11.2026. Суффикс 09.11 сохранён по заданию. CSV — исследование, без записи в БД.

HEX означает размер обжимной матрицы, а не гайки. [Amphenol 901-10777 Rev B](https://www.amphenolrf.com/en-us/assets/file/4068904535/), лист 2 из 2, примечание 5F: для RP-SMA jack на кабель диаметром 1,37 мм требуется обжим корпуса поверх внутренней втулки. Пересчёт заданного в дюймах размера даёт **2,667 мм**. Допуск матрицы явно не назначен. Обозначения RF 1.37 недостаточно, чтобы перенести это значение на деталь цеха: нужен её артикул. Шестигранник корпуса/гайки в этом чертеже — другой размер.

По экранам: [QMA-KPD7](https://amel.ru/upload/iblock/417/QMA-KPD7.pdf), стр. 1, является приборной розеткой. Кабельный тип экрана для неё не назначен. Чертежи XAHONOR [SMP-KW3](https://amel.ru/upload/iblock/64b/SMP-KW3.pdf) и [SMP-KW2.5D](https://amel.ru/upload/iblock/00b/SMP-KW2.5D.pdf), каждый лист 1 из 1, назначают кабели; [таблица Amphenol](https://www.amphenolrf.com/en-us/engineering-center/engineering-resources/coaxial-cable-guide/), HTML, строки соответствующих кабелей, подтверждает оплётку. Для второго исполнения двойную оплётку прямо показывает [Anoison RG316D Rev A](https://www.anoison.com/wp-content/uploads/RG316D.pdf), стр. 1, Construction Specification. Это вывод по назначенному кабелю, не по буквам артикула.

**SSMC female и «СР-50 типовой» недостаточно конкретны.** [Radiall, раздел SSMC](https://www.radiall.com/media/document_library/2021_CoaxCatalog_Section_12_v1_1.pdf), стр. 12-13, содержит варианты для гибких и полужёстких кабелей. Тип экрана не переносится на всё семейство. Для СР-50 нужны полный индекс и кабель.

Измерительная база указана в каждой строке: кончик штыря, его основание и передний срез гнезда — разные точки. REF не всегда совпадает с торцом корпуса. Односторонние пределы сохранены как пределы, без придуманного ±. Названия SMB plug/jack даны вместе с типом контакта: у SMB plug имеет гнездо, jack — штырь; автоматическое сопоставление с русскими названиями недопустимо.

[Amphenol Coax Europe](https://docs.rs-online.com/3907/0900766b80e03eb5.pdf), печатные стр. 8 и 18: MCX plug — G; jack — F−E. В CSV используется один источник без смешивания округлений. Для MMCX plug C — локальное утопание контакта; это не полная длина до REF. Для jack конечная верхняя граница не установлена. Привязка этих интерфейсных баз к конкретному корпусу остаётся отдельной проверкой.

Для [FME Rosenberger](https://www.rosenberger.com/fileadmin/content/headquarter/Downloads/RF_Coaxial_Connectors/Communication_Products_Catalog_2014.pdf), стр. 308, найден интерфейс, но цеховая размерная цепь не установлена. [RadioLab UHF](https://www.radiolab.ru/ru/attach_file/uhfradiolab.pdf), стр. 1, показывает номинальную длину выступающей части штыря **9,14 мм**, без допуска. Она не перенесена в глубину от торца корпуса. Ранее записанные значения БД не являются источником этого исследования.

MIL-STD-348B: доступность и редакция

- [DLA, постоянный PDF](https://landandmaritimeapps.dla.mil/Downloads/MilSpec/Docs/MIL-STD-348/std348.pdf) — полный извлекаемый текст **Change 4 от 12.08.2024** доступен через веб-инструмент. Прямая загрузка Python из среды запрещена сетевыми ограничениями; локальная копия PDF не создана.
- [DLA ASSIST QuickSearch, карточка 35726](https://quicksearch.dla.mil/qsDocDetails.aspx?ident_number=35726) — Active, последняя содержательная редакция B Change 4. Notice 1 — отдельное подтверждение действительности, не следующая содержательная редакция.
- [EverySpec, раздел 0300–0499](https://everyspec.com/MIL-STD/MIL-STD-0300-0499/) — каталог открывается, но ссылка на 348B/Change 4 не найдена. Доступность нужного PDF не подтверждена.
- [Abbott Aerospace, MIL-STD-348B](https://www.abbottaerospace.com/downloads/mil-std-348b-radio-frequency-connector-interfaces-for-mil-c-3643-mil-c-3650-mil-c-3655-mil-c-25516-mil-c-26637-mil-c-39012-mil-c-49142-mil-a-55339-mil-c-83517/) — карточка открывается, полный PDF и Change 4 не подтверждены.

SMB jack: C−D; plug: верхняя граница F+D. Расчёты CSV выполнены по справочным метрическим эквивалентам MIL. Основные размеры стандарта дюймовые. MCX/MMCX, FME и UHF в доступном тексте не найдены; номера рисунков им не назначены.

Открыто: идентификация RP-SMA, SSMC, СР-50; актуальные чертежи FME/UHF/MMCX jack; привязка торца корпуса к REF. Строки с иной или неподтверждённой базой не готовы к автоматическому заполнению БД.
