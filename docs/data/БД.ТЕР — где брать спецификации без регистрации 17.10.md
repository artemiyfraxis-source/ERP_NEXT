# БД.ТЕР — где брать спецификации обжима без регистрации, 17.10.2026

Задача владельца: «найди способ получать это сам, без меня». Проверено 17.10 с рабочей машины, выход в интернет —
Москва (IP RU). Результат — «БД.ТЕР — обжим из открытых источников 17.10.csv»: **91 ячейка высоты по жиле из 148
пустых** (без изолированных наконечников и закрытых стволов), все значения — из документов производителя, у каждой
есть номер документа и ссылка. В базу ничего не записано.

## Главное: почему вчера всё было «403»

Это не защита от ботов, а **гео-блок России**. te.com, mouser, farnell/newark, rs-online, digikey, octopart, alliedelec,
TTI, molex.com, r.jina.ai отдают 403 / «Access Denied» / 451 даже настоящему браузеру. WebFetch (запрос из США)
тоже получает 403 у mouser/farnell/octopart — там антибот. Поэтому прямые ссылки на эти сайты отсюда бесполезны.

## Как повторить

1. Чтобы узнать номер спецификации TE, открыть в архиве даташит `te.com/en/product-<PN>.datasheet.pdf` и взять ссылки
   «Specification Or Standard».
2. Найти документ через CDX (фильтр `DocNm=<номер>&`) и скачать его по `id_`-ссылке. Всё это — только из браузера.
3. Если в документе нет таблицы — взять «Customer Drawing» (у немецких серий TE таблица обжима обычно на чертеже,
   например 1355064).
4. JST — через Application Tooling Guide. Molex, JAE, Hirose из РФ пока не достать: нужен доступ из другой страны.
