## Как искали

1. Существующие ссылки gsm-repiteri (309 уникальных страниц, 412 строк) открыты все. Артикул на странице совпал
   с артикулом из «Артикул поставщика» во всех случаях. Цена взята из карточки («Цена: N р.», это цена за 1 шт.).
   «Артикул поставщика» gsm-repiteri — это id товара на сайте (`product_id`).
2. kroks.ru: обойдён весь раздел «Разъёмы» и «Высокоточные разъёмы» (312 карточек), артикул kroks — номер
   «арт.» на карточке. Цена за 1 шт. с карточки.
3. vegatel.ru: поиск по коду R…; код на карточке совпал у всех 9 позиций.
4. amel.ru: поиск по артикулу на сайте. Ссылка — на карточку товара, вид соединителя и кабель сверены
   с описанием на ней.
5. Строки без поставщика: подбор по серии, полу, прямой/угловой и кабелю по каталогу gsm-repiteri
   (352 карточки разъёмов), затем по kroks и АМЭЛ. gsm-repiteri брали первым, kroks — если у gsm позиции нет
   в наличии или в БД записан продавец kroks. Для RG-142 / RG-141 / RG-400 / RG-223 подобраны разъёмы под RG-58:
   размер обжима у них тот же, это отмечено в «Как найдено».
6. Позиции конкретных брендов — chipdip.ru по точному артикулу. Из нескольких предложений выбиралось то, что
   лежит на складе chipdip, затем с самым коротким сроком, затем самое дешёвое.
