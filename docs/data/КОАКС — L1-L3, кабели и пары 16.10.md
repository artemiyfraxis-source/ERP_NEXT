# БД.КОАКС: L1–L3, кабели и пары RG-174 ↔ RG-316, 16.10.2026

Владелец: «ты все решаешь сам и закрываешь». Вечером 16.10 он добавил два правила:
- «"примерно" не надо, будем на деле проверять». В базу идут только значения, без пометок. Как получено каждое
  значение, записано только в журнале.
- У разъёма хранятся только его собственные данные. D1–D3 берутся из кабеля (СПР.КАБ), поэтому в строки БД.КОАКС
  они не пишутся и не копируются.

Файлы:
- Журнал ячеек и откат: «КОАКС — L1-L3, кабели и пары 16.10.csv», 141 строка. В каждой строке: задача, ключ,
  поле, было, стало, как получено, URL, статус dry.
- Скрипт записи: «КОАКС — L1-L3, кабели и пары 16.10 запись в прод.py», режимы `dry` и `apply`. Строка ищется по
  ключу «артикул + кабель», у каждой ячейки сверяется старое значение (""). Запись идёт через `_edit_in`
  (как «Изменить» на экране), новые строки — через `import_rows("coax")`.

**В прод не записано.** Dry на проде 16.10 вечером (БД.КОАКС 582 строки): 135 «проверено», отказов 0, импорт —
created 9 / updated 0 / refused 0. Порядок записи: `backup-now` → `apply` → `dry`. После записи dry должен
дать только «уже так» и «уже есть».

Снимок для задачи взят 16.10 днём. Параллельно на проде заполнялся «HEX обжима» (311 строк, другая работа). Пары
задачи 3 собраны по свежему снимку, поэтому HEX копируется вместе со строкой. У всех 62 разъёмов, которые уже стоят
на обоих кабелях, HEX на RG-174 и на RG-316 одинаковый.

## 3. Девять разъёмов RG-174 / RG-316 без источника: 9 новых пар

Добавлены пары: BNC-C174J, BNC-C174P, TNC-C174P, SMA-C174J, SMA-LC174P на RG-316; SMA-C316F, CRC9, TS9 и
SMA-Female фланцевый RG316 на RG-174.

Почему: RG-174 и RG-316 — одна группа обжима (D2 1,52 / 1,48, Ø 2,8 / 2,5). Изготовители выпускают один разъём
на «RG-174/188/316». В базе 47 разъёмов уже стоят на оба кабеля.

Как сделана новая строка: это копия строки разъёма с другим кабелем. D1–D3 не копируются. Из «Источника данных»
убран хвост «L1–L3 примерно…».

## 4. Восемнадцать пар «/5D» на RG-59 / RG-6 / SAT-703: оставлены, без пометки

Эти пары называет сама страница поставщика. Предупреждение «75 Ом / жила тоньше контакта» в БД не пишется: по
новому правилу пометок в базе нет. Ни одна складская партия, заявка или комплект не держит пару по кабелю: они
хранят разъём только по имени. N-111/5D встречается в 1 строке заявки и в 1 комплекте ТК, без кабеля. Удалять
нечего.

## Не трогал, к сведению

- В 427 строках, записанных 15.10, в «Источнике данных» остался хвост «L1–L3 примерно: …». По новому правилу его
  надо убрать отдельной правкой, если владелец подтвердит, что это касается и старых записей.
- D1–D3, которые уже стоят в строках БД.КОАКС, уберёт отдельное изменение (владелец 16.10).
