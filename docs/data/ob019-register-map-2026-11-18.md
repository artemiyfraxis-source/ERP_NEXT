# ОБ.019 — карта регистров Modbus линии резки и зачистки с лазерной маркировкой (18.11.2026)

Станок: ОБ.019 «Автомат резки и зачистки провода с лазерной маркировкой», Eastontech EW-3185+L. ПК станка — Windows 7.
Штатный пульт — программа PXS_HMI («派单上位机_V1.00_new», .NET, библиотека экранов PCHMI). Лазер — EZCAD2 с
отдельной программой-мостом «modbus auto mark software(20241002)».

Документ нужен для собственной программы управления ОБ.019 из ERP, которая заменит PXS_HMI. В ней будут живая
панель, параметры и задание, команды Сброс/Пуск/Стоп/режимы/Jog и передача счётчиков в ERP.

Статус адреса:
- **проверено** — значение прочитано или записано по шине 18.11 и совпало с экраном HMI.
- **из файлов** — взято из конфигов и декомпиляции PXS_HMI/PCHMI (привязки элементов экрана к адресам), на шине
  не проверялось.
- **предположение** — вывод из косвенных данных.

## 1. Связь

| Пульт ↔ ПЛК линии | COM8 (FTDI USB-RS485) | Modbus RTU, 38400, 8N1, адрес 1, тайм-аут 100 мс | PXS_HMI | ПЛК линии | `binexe/PLC-CONFIG.xml` (`ANY_MODBUS_RTU;COM=8,38400,0,8,1;SN=1;…`), **проверено** |
| Лазерный мост ↔ ПЛК линии | COM1 | Modbus RTU, 38400, 8N1, адрес 1 | мост (NModbus4) | ПЛК линии (второй порт) | лог моста `logs/2025/08/2025-08-18.log` («com:1,nBaund:38400…»), `cfg.ini [ModusTcp]` |

- `E:\DY\RS485_set.ini` (COM8, 19200) — настройки утилиты прошивки по RS485. PXS_HMI их не использует.
  `CutLineMach.ini [剥线机通讯参数]` (COM6), `InkMach.ini`/`PipeMach.ini` (COM8, 38400) — старые или неиспользуемые разделы.
- **Ведущий на COM8 может быть только один.** Пока PXS_HMI запущен, порт занят. Своя программа работает только при
  закрытом PXS_HMI. Лазерный мост сидит на COM1 и с нами не конфликтует.
- **Правила адресации** (`PLC-CONFIG.xml` + драйвер PCHMI `MCMD.TXD`, **проверено** на D32/D440):
  - `Dn` = holding-регистр n с нуля (смещения для D нет). Чтение FC03, запись FC16. FC06 не используется
    (`IS06MOD=False`): HMI пишет даже одно слово функцией 16.
  - `Xn` — дискретные входы FC02 (`IS02MOD=True`), смещение 0. `Yn` — катушки FC01/FC05/FC15, смещение 0.
    `Mn` — катушки со смещением 2048 (`MOFFSET=2048`). Номера X/Y десятичные.
  - 32-битные значения: младшее слово первым (`DWLargeEnd=False`). Пример: D32=0x7EF4, D33=0x0000 → 32500 → 325,00 мм.
  - Строки: 2 ASCII-символа на регистр, **старший байт — первый символ**, хвост заполняется нулями. Поле на 15 регистров
    вмещает 30 символов. PXS_HMI перед записью меняет байты местами (`SwapStr`), так что на шине порядок естественный.
  - `Dn.b` — бит b (0…15) в слове Dn. Записать бит = прочитать слово (FC03), изменить бит, записать слово (FC16).
    Так делает PCHMI (`MCMD.Send_Control`, ветка `"DPT"`).
  - Адреса `Un` в коде HMI — внутренняя память PXS_HMI, на шину не идут (`REG.SEND_LWord`: `UR[pid,…]`).

## 2. Что проверено на станке 18.11.2026

1. Чтение FC03 при закрытом PXS_HMI:
   - D32..D41 = `7EF4 0000 0000 0000 0000 0000 0000 0000 0000 0000` → длина 325,00 мм, зачистки 0,00, как на экране.
   - D440..D454 = «C1.5 to XS17.7», дальше нули и остаток старого текста «s8 6» в D449–D450.
2. Запись FC16 в D32..D33 = `7F58 0000` (326,00 мм):
   - эхо `01 10 00 20 00 02`, CRC верна;
   - обратное чтение 32600;
   - владелец открыл PXS_HMI — на экране 326.00. **HMI при старте не перезаписывает параметры ПЛК**, а читает их.
   - Владелец вернул 325 вручную в HMI.
3. Снимок экрана и UI Automation Home:
   - поля Home в дереве UIA недоступны для записи: нет ValuePattern, `IsEnabled=False`;
   - ввод идёт через экранную клавиатуру PCHMI по щелчку (`INTYPE=1`);
   - элементы других вкладок в дереве отсутствуют, пока вкладка не открыта.

### 3.2 Команды

- **1 «瞬动», удержание** — при нажатии бит = 1, при отпускании бит = 0 (`DCON.Send_Dt_Wdt`: KeyVal 1 → 置位, 0 → 复位).

- **14 «字写入»** — запись числа в слово.

**Лазерный мост — обмен с ПЛК** (`cfg.ini [ModusTcp]` + лог моста). Мост — ведущий Modbus на COM1, ПЛК — ведомый №1.
1. ПЛК подаёт сигнал на вход 6 платы лазера (`StartPort=6`).
2. Мост читает D810..D824 (`MarkDataAddr=810`, `MarkData_Len=15`) — текст метки.
3. Мост читает D809 (`ezdNameAddr=809`, 1 регистр) — имя шаблона, 2 ASCII-символа. Например, 0x3231 = «21» →
   `…\SYKJ\Desktop\123\21.ezd`.
4. Мост открывает .ezd, подставляет текст в объект с именем `SN` и маркирует.
5. Мост пишет **D808 = 1** (`MarkEndAddr=808`) — маркировка закончена. По инструкции моста 0 означает ошибку.

Связь с текстами HMI. В D810 мост видел «XS12.4 to C2.1» с тем же хвостом «s8 6», что лежит в D449–D450 сейчас.
Значит, ПЛК копирует нужный блок D440/D455/D470 в D810 перед каждой меткой (предположение). Своя программа должна
писать тексты в D440/D455/D470 и **очищать хвост нулями**. Номер шаблона в D809 HMI не задаёт — его пишет ПЛК
(откуда — открытый вопрос). Лог 18.08.2025: 2468 меток подряд, шаблон «21», цикл ≈ 0,5–0,8 с.
