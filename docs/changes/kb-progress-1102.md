# Количества по КБ — незавершённая задача TASKS

Накопительные отметки «Начато / Готово / На ОТК / ОТК прошло» по КБ. Позднее количество поднимает ранние с уведомлением; отрицательное и превышение тиража не допускаются. Порядок этапов не блокирует работу во время тестирования.
Это предпосылка отдельного разрешения упаковки по КБ и количеству. Реальные складские движения не подменяются ручными отметками.

Статус: точечный план и реализация в отдельной ветке; проверка миграции обязательна, если она понадобится.
