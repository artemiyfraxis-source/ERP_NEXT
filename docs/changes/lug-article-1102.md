# Артикулы наконечников

Задача: убрать ошибочное разделение наконечников на катушку и пакет, показывать единый столбец «Артикул».
Сохранить оба исходных значения без потерь, редактирование и обмен файлами. Реальные катушки контактов не менять.
Без изменений производственных данных и схемы БД.

Реализован единый вычисляемый артикул: одинаковые значения не дублируются, разные сохраняются через « / ».
Исходные поля и правка записи не меняются; новый ключ представления применяется только к наконечникам.
Регрессия воспроизведена до исправления; 52 целевых теста и TypeScript прошли, независимое ревью без замечаний.
Полный gate, снимки трёх экранов и статус выпуска — в PR.
