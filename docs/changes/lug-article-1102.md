# Артикулы наконечников

Задача: убрать ошибочное разделение наконечников на катушку и пакет, показывать единый столбец «Артикул».
Сохранить оба исходных значения без потерь, редактирование и обмен файлами. Реальные катушки контактов не менять.
Без изменений производственных данных и схемы БД.

Статус: реализация и проверки в работе.
