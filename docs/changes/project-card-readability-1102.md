# Читаемость карточек проектов

По повторному замечанию владельца: уменьшить пустой зазор перед проблемами, дать заказчику две строки и сделать замечания ТК/КБ заметнее. Изменения ограничены стилями карточек, без изменения данных, статусов и действий.

Карточка имеет минимальную ширину 320 px с адаптацией к узкому экрану. Заказчик занимает до двух строк, замечания показаны шрифтом 13 px и переносятся целиком. Убрана резервная высота 44 px под статусом.

64 теста ProjectCard и ProjectsPage прошли; независимое ревью CSS без замечаний. Итоговые сборка, визуальная оценка и общий gate выполняются на интеграционном пакете.
