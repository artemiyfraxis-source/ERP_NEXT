# Единая приёмка с производства

- Убран устаревший блок «Коробки из цеха после ОТК» и отдельная загрузка его данных.
- Приёмка по КБ, печать и разрешение отгрузки без УПД остаются без изменений.
- Старый HTTP-маршрут передачи коробки сохраняет проверку прав, но отвечает 410 с переходом к новой приёмке. Он не открывает UnitOfWork.
- Исторические коробки, серийные номера, акты и внутренняя доменная функция не изменяются. Миграции нет.
- Демонстрационный сценарий использует новую приёмку по КБ и количество подтверждённой коробки, а не всего заказа.

Проверки: 113 frontend-тестов, TypeScript, 70 backend-тестов; один сценарий с частной выгрузкой пропущен без источника.
Сквозной синтетический сценарий после новой приёмки дважды вызывает старый маршрут и сверяет полные строки готовой продукции, движений, актов, последовательностей, коробок, серийных номеров, приходов, аудита и outbox.
Дополнительно проверены 403 без права и отсутствие обращения к фабрике UnitOfWork.
Экран 1536×864 проверен на синтетических данных: новый путь доступен, старого блока нет, горизонтального переполнения страницы и ошибок браузера нет.
