# Личные колонки загрузки цеха

В «Производственном плане → Загрузка цеха» кнопка «Колонки» открывает тот же компонент, что на складе:
галочки и стрелки ↑/↓. В плане порядок также меняется перетаскиванием за ручку. После перестановки
заголовки, ячейки, ширины и отступы закреплённых колонок используют один порядок; календарь остаётся справа.
«Проект» всегда виден первым. Стрелки доступны с клавиатуры, сохраняют фокус; Escape закрывает список.

Вид `{order, hidden, autoFit}` сохраняется через существующий API личных настроек под ключом
`production-plan.load`. Локальная резервная копия использует `erp-zg-columns:user:<user.id>`.
Старый общий ключ `erp-zg-columns` не переносится и не удаляется. Неизвестные и повторные ключи
отбрасываются; добавленные позднее колонки остаются доступны. «По ширине экрана» сохраняет режим
автоматического подбора колонок и стандартный порядок, в том числе для другого устройства.

Учётная запись передаётся из текущего `principal.user.id`. Перед сменой сессии отменяются отложенные
записи настроек; ответы предыдущей сессии игнорируются. Поздний начальный GET не заменяет более свежие
изменения ни на открытом листе, ни в общем кэше после ухода и повторного открытия экрана.

В списке «Комплект проверен» и «Тестовая сборка» обозначены как ручные отметки, «Техкарта выдана»
и «Комплект набран» — как также доступные в статусе. Значения отметок и сохранённый выбор не меняются.
Расчёты процентов, порядок строк, бизнес-правила и автоматическое обновление плана не затронуты.

## Проверка

- `npx vitest run src/personalViews.test.ts src/App.test.tsx src/PlanLoadSheet.test.tsx src/ProductionPlanPage.test.tsx src/WarehousePersonalColumns.test.tsx src/WarehousePage.test.tsx --no-color`: 155 тестов, 6 файлов — успешно.
- `npm run build -- --clearScreen false`: TypeScript и production-сборка успешны. Существующие предупреждения о BigInt в legacy-сборке редактора жгутов не относятся к изменению.
- Smoke в изолированном браузере на локальном Vite, 1536×864, с настоящим React-компонентом и подставленным API: Enter на стрелке меняет порядок и сохраняет фокус; drag меняет согласованно заголовки и ячейки; скрытие колонок сохраняется; Escape возвращает фокус; восстановление только с сервера после очистки localStorage сохраняет порядок. Ручная отметка тестовой сборки осталась включена; прокрутки всей страницы по горизонтали нет. Окно колонок просмотрено на скриншоте.

Полный интеграционный gate, независимое ревью и проверка трёх размеров выполняются оркестратором перед выпуском.
