# Личный набор и порядок столбцов производственного плана

Пользователь выбирает видимые столбцы и меняет их порядок, как в других таблицах. Настройка сохраняется за аккаунтом через существующий механизм личных представлений и доступна на другом компьютере. Общие бизнес-отметки проекта остаются общими.

Старые настройки браузера не должны переносить чужой набор при смене аккаунта. Неизвестные ключи отбрасываются, новые доступные столбцы не ломают сохранённый порядок. Ручные и дублирующие поля явно обозначаются в выборе, история и расчёты не удаляются.

Claim до кода, база `5b14a8fa8a1a8e1b0b908b7c1be571a322331501`. Миграция не требуется. Проверки сохранения, порядка, переключения аккаунтов, недоступного хранилища, независимый review, gate и короткий smoke ещё предстоят.
