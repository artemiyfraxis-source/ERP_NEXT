# Отказ закупщика по новой заявке

В «Закупки → Заявки → Мои» у новой строки без закупщика доступна кнопка «Отказать» рядом с «Взять в работу». У своей строки сохраняется «Отменить». Обе команды и массовая отмена открывают окно `PageWindow` с названием позиции либо количеством выбранных строк и обязательной причиной до 500 символов.

Используется существующий `POST /api/procurement/cancel-many`: сервер одной транзакцией отменяет строку и назначает закупщика, сохраняет причину в аудите и истории. Отдельного запроса взятия в работу нет. Новых статусов, миграций и изменений складских операций нет. Выбор строк для массовых действий не расширен.

Пустая причина не отправляется, пробелы по краям убираются. Повторная отправка блокируется на время запроса. При HTTP-ошибке окно сохраняет текст и показывает ошибку; пропущенные строки перечисляются с серверной причиной. В «Все» и при доступе только на просмотр действия скрыты. Чужие, оплаченные, закрытые, полностью покрытые со склада строки и дозавозы не получают разрешение на отмену.
