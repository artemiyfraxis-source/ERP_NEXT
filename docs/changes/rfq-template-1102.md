# Личный шаблон запроса КП

Зона задачи: RfqLetters и тесты. Сохраняемый на сервере личный текст шаблона, явное сохранение и ошибки; позиции и количества подставляются из текущего КП. Без миграции, изменения складских данных и автоматической отправки писем.

Статус: задача заявлена, реализация и проверки впереди.
