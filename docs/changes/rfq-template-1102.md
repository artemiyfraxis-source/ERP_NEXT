# Личный шаблон запроса КП

Зона задачи: RfqLetters и тесты, связанная интеграционная проверка PurchasingRfq (загрузка настройки, ожидание письма, изоляция URL между тестами). Сохраняемый на сервере личный текст шаблона, явное сохранение и ошибки; позиции и количества подставляются из текущего КП. Без миграции, изменения складских данных и автоматической отправки писем.

Реализация: «Изменить шаблон» → редактор → «Сохранить шаблон». Настройка `rfq.letters` хранится через существующий серверный API личных настроек, отдельно для каждого пользователя. Сохраняется только исходный текст, не заполненное письмо. Нет общего кэша и локального резервного сохранения, выдаваемого за серверное.

Обязательная подстановка — `{{позиции}}`; необязательные — `{{срок_ответа}}` и `{{ступени_цены}}`. Если необязательных подстановок нет, актуальные срок и ступени добавляются в конец письма. Обычные одиночные фигурные скобки допустимы, неизвестные двойные подстановки отклоняются. Лимит — 6000 символов, в том числе для загруженной настройки. Это оставляет запас до серверного ограничения JSON.

Позиции, количество, срок и набор позиций конкретного поставщика формируются из текущего запроса. Подстановка однопроходная: текст наименований не интерпретируется как шаблон. Плановая цена из расчёта не подставляется. Существующие копирование, открытие почты и отметка отправки сохранены; редактирование шаблона само по себе ничего не отправляет.

До загрузки настройки письмо не выдаётся. При ошибке доступны повторная загрузка или явное использование стандартного текста без записи на сервер. Неудачное сохранение оставляет прежний действующий шаблон и введённый черновик; двойное сохранение заблокировано. Во время редактирования письмо явно подписано как построенное по сохранённому шаблону.

Проверки: сценарии загрузки/повторной загрузки, сохранения/ошибки/перезагрузки, смены пользователя, текущих данных, границ длины, неизвестных подстановок, повреждённой настройки и сохранения в процессе. Реальный компонент с синтетическими данными просмотрен при ширине 1536 px, без горизонтального переполнения и ошибок браузера. Полный интеграционный gate и независимое ревью выполняет оркестратор.

Миграция: нет. Продакшен-данные не использовались и не менялись.

Результат: 29 тестов в четырёх связанных файлах, TypeScript и проверка diff — успешно. Независимое ревью итоговых четырёх файлов — APPROVE; оркестратор также просмотрел финальный скриншот. Публикация ветки разрешена владельцем, объединение и выпуск — после общего gate и CI.
