# Исторические реквизиты отправок

Завершённые отправки должны сохранять свои реквизиты при изменении текущей карточки проекта. Контролируемая правка администратором требует версии записи, причины, источника и аудита значений до и после. Количества, документы, складские движения и даты не входят в исправление реквизитов.

Зона первого этапа: shipping domain/application/api и тесты. Без миграции. Рабочие данные автоматически не исправляются.

Статус: задача занята, реализация впереди.
