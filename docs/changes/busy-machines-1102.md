# Только занятые станки

Задача: в сетке загрузки показывать только станки с положительным занятым временем в отображаемые дни. Счётчики площадок отражают показанные станки; пустые группы скрыты, при отсутствии загрузки есть короткое сообщение с периодом.

Зона: MachineLoad.tsx и связанные тесты. Данные оборудования и расчёты загрузки сохраняются. Миграция не требуется.

Статус: задача занята, реализация и проверки впереди.
