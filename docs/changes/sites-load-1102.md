# Загрузка ЖУК и ЦАР

Задача: разделить монтажников и загрузку станков по площадкам, сохранив общий календарь.
Мощность считать только по станкам соответствующей площадки. Отсутствующие станки ЖУК и неизвестную площадку показывать явно; не придумывать загрузку.
Без изменений производственных данных, схемы БД и планировщика.

Реализованы отдельные группы монтажников и станков ЦАР / ЖУК с общим календарём.
Неизвестная площадка показана отдельно; для смешанной бригады и неизвестной мощности отображаются часы без ложного процента.
Свободный ручной инструмент не засоряет список станков; фактически занятую оснастку не скрываем.
Целевые проверки: frontend 25 тестов, backend 16 тестов, TypeScript; независимое ревью без замечаний.
Полный gate, снимки трёх экранов и статус выпуска — в PR.
