# Загрузка ЖУК и ЦАР

Задача: разделить монтажников и загрузку станков по площадкам, сохранив общий календарь.
Мощность считать только по станкам соответствующей площадки. Отсутствующие станки ЖУК и неизвестную площадку показывать явно; не придумывать загрузку.
Без изменений производственных данных, схемы БД и планировщика.

Статус: реализация и проверки в работе.
