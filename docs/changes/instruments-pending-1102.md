# СИ с неподтверждённой поверкой

Для переноса существующих тестеров в реестр средств измерения нужна явная регистрация без сведений о поверке. Прибор получает статус «Поверка не подтверждена» и не доступен для контроля качества до подтверждения. Действующие СИ сохраняют свои данные и проверки.

План: nullable сведения поверки с ограничениями БД, явный статус регистрации, отображение отсутствующих данных и безопасная печать. Миграция после 0166. Реальные идентификаторы переноса и результаты сверки хранятся отдельно от публичного репозитория.

Статус: задача занята. Миграция, проверки и репетиция впереди; перенос рабочих записей ещё не выполнен.
