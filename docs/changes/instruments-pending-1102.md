# СИ с неподтверждённой поверкой

Для переноса существующих тестеров в реестр средств измерения нужна явная регистрация без сведений о поверке. Прибор получает статус «Поверка не подтверждена» и не доступен для контроля качества до подтверждения. Действующие СИ сохраняют свои данные и проверки.

План: nullable сведения поверки с ограничениями БД, явный статус регистрации, отображение отсутствующих данных и безопасная печать. Миграция после 0166. Реальные идентификаторы переноса и результаты сверки хранятся отдельно от публичного репозитория.

Backend: явный статус «Поверка не подтверждена» принимает только отсутствующие номер и даты поверки. Старый запрос без статуса по-прежнему регистрирует действующее СИ с полным комплектом сведений. ОТК и КСВН отвергают неподтверждённые приборы; ответы реестра и паспорта поддерживают отсутствующие значения.

Миграция `0167_instrument_verification_pending` после `0166_kb_progress` сохраняет записи и ссылки, добавляет ограничения статуса, полноты и порядка дат. Некорректные старые записи останавливают миграцию без исправлений. Откат при неизвестной поверке запрещён до изменения схемы. Синтетический CI-seeder получает допустимый статус и комплект поверки: прежняя схема позволяла ему генерировать произвольный статус.

Проверено на выделенной ветке от `d5d022dd`: 62 backend-теста прошли, включая API, ОТК, КСВН, миграцию SQLite с сохранением связанных записей и единственность Alembic head. Проверки интерфейса, независимое ревью, общий gate и репетиция PostgreSQL ещё впереди. Перенос рабочих записей не выполнен.
