# Заявки без отдельного «Взять в работу»

Задача занята: убрать промежуточную кнопку в заявках закупщика. Новая позиция остаётся новой при просмотре и подборе поставщиков; ответственный назначается атомарно при создании запроса КП. Отказ с обязательной причиной сохраняется.

План: разрешить выбор новых свободных позиций для КП, объединить назначение и создание КП в одной транзакции через существующий межмодульный порт, сохранить ограничения чужих позиций, дозавоза, оплаты и покрытия складом. Общий ручной take API и другие экраны не удаляются.

Миграция не требуется. Реализация, проверки конкуренции, независимое ревью и полный gate впереди. Рабочие данные не изменялись.
