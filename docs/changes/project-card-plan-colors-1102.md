# Цвета карточек проектов как в плане

Единая семантика цветов карточек и производственного плана: готовность зелёная, незавершённость нейтральная, ожидание жёлтое, остановка красная. Сохраняются фактические счётчики, подписи, действия и состояния частичной готовности. Цвет проекта берётся из существующей палитры плана, если применим.

Карточки показывают существующие отметки готовности `ProjectMarks`, как строки плана. Счётчики незавершённых действий нейтральные; погрешности остаются красными. Ручные отметки и их подсказки сохранены. Узкая декоративная метка рядом с номером использует общий детерминированный `projectColor` и существующие токены палитры плана, включая тёмную тему.

Проверки: 97 тестов ProjectCard, ProjectsPage, ProjectStatus, ProductionPlanPage; TypeScript без ошибок. Реальные компоненты просмотрены на синтетическом стенде 1536×864: новый проект, частичная комплектация 4 из 40, готовность, ожидание, СТОП, ручные отметки и пустой состав. Нет горизонтального переполнения страницы или ошибок JavaScript. Временный стенд удалён после проверки.

Визуальный аудит: семантика цветов совпадает с планом, готовность не скрывает оставшиеся счётчики. Номер проекта и заказчик читаются первыми; небольшая цветовая метка не окрашивает карточку целиком. Аудит доступности: метка декоративная, текстовые статусы и доступное описание сохранены, существующие Enter/Пробел и видимый фокус не изменены.

Без изменений данных и миграций. Независимое ревью, интеграционный gate и выпуск выполняет основной агент.
