# Цвета карточек проектов как в плане

Единая семантика цветов карточек и производственного плана: готовность зелёная, незавершённость нейтральная, ожидание жёлтое, остановка красная. Сохраняются фактические счётчики, подписи, действия и состояния частичной готовности. Цвет проекта берётся из существующей палитры плана, если применим.

Без изменений данных и миграций. Реализация, визуальная проверка, независимое ревью и общий gate впереди.
