# Ссылки на комплектующие в комплектации — 02.11.2026

В «Запросах на комплектацию» покупное наименование выделено жирным, артикул КД остаётся обычным текстом.
Сохранённые ссылки на комплектующее доступны и во вкладке «Весь заказ», и внутри каждой КБ. В общем заказе
ссылки одинаковых позиций объединяются без повторов, в том числе после разделения строки по партиям.
Количество, статусы и выбор ГРН работают по прежним правилам. Ссылки доступны при праве просмотра,
открываются в новой вкладке и не редактируются на этом экране.

API при чтении страницы заявок одним пакетным запросом получает текущие карточки наборов. Сопоставление
строгое: проект, КБ, артикул и покупное наименование; для пустого имени компонента используется артикул,
как при создании заявки. Старые заявки тоже получают ссылки при сохранившемся совпадении. Это текущая
справочная ссылка из состава, а не исторический снимок закупки: если компонент удалён или переименован,
ссылка не подставляется. Закупка не используется как запасной источник без достоверной привязки к КБ.
Пропускаются только абсолютные HTTP(S)-адреса с узлом, без учётных данных, управляющих символов,
пробелов внутри адреса, обратных слешей и некорректного порта. Внешние адреса сервер не запрашивает.
Изменений схемы, складских операций и записей в производство нет.
