# Строгий выбор сканера

Выбор хранит конкретные ПК и сканер. Перед запуском ERP заново получает список устройств: отсутствующий сканер,
выключенный ПК, ошибка получения списка или устаревший агент открывают выбор без отправки задания другому устройству.
Одинаковый IP браузера и агента больше не назначает сканер автоматически. Сброс удаляет и прежний выбор ПК в браузере.
Смена или сброс выбора во время загрузки отменяют запуск по прежней паре; поздний ответ настроек не возвращает её.

В окне показаны отдельные устройства как «ПК · сканер». Неактивные ПК и агенты до версии 2.2.0 видны с причиной,
но выбрать их для команды нельзя. Сервер проверяет ту же пару и версию независимо от интерфейса; предложение
обновления ещё не означает установленное обновление. До следующего отчёта агента 2.2.0 сканирование на нём ожидает.

Агент 2.2.0 сообщает все доступные ему WIA-сканеры (тип 1) и настроенный eSCL отдельно. Исчезнувшее устройство
не заменяется первым. При нескольких одинаковых именах нужен идентификатор. Выбранный WIA не заменяется настроенным
eSCL. Ручной старый запуск без выбора допускает только единственное WIA-устройство; при нескольких требуется выбор.
Версия, скачиваемый файл и его SHA-256 берутся из существующего механизма выпуска агента.

Проверки в отдельном worktree на базе `8b3b496d4bb42824ca5aec1838c436f0d6428971`:

- Backend: `test_scan_agents.py` + `test_scan_jobs.py` — 49 успешно, 2 пропущены (локально нет Tesseract).
- Frontend: `ScanAgent.test.tsx`, `WarehouseScan.test.tsx`, `ShipmentData.test.tsx`, `ShipmentDataPage.test.tsx` — 62 успешно.
- PowerShell/Pester 3.4: `agent-scan.Tests.ps1` + `agent-registry.Tests.ps1` — 30 успешно; WIA, сеть и обновление замоканы.
- `npm run build` (TypeScript + Vite) — успешно; существующие предупреждения о BigInt в редакторе жгутов.
- Локальное окно настоящего React-компонента просмотрено при 1536×864 на тестовых ПК и трёх сканерах: выбранное
  устройство выделено, неактивные варианты объяснены и недоступны, горизонтального переполнения нет. Проверены
  русские подписи, существующие стили, кнопки/клавиатура, уведомления загрузки и ошибок; тяжёлый demo-прогон
  заменён согласованной локальной проверкой компонента.

Проверки не доказывают доступность трёх физических устройств владельца через WIA. Реальные драйверы, TWAIN,
физическое сканирование и production в этом изменении не проверялись. Миграций и изменений складских данных нет.
Независимые code/security review и полный интеграционный gate остаются у основного агента перед выпуском.
