# Поиск поставщиков при запросе КП

Зона задачи: RfqPool и тесты. Поиск в предложенных и выбранных поставщиках без потери скрытого выбора и изменения отправляемого набора. Без миграции и изменения правил закупки.

Добавлен отдельный поиск по списку предлагаемых/выбранных поставщиков при создании запроса и подборе в существующий запрос. Поле добавления поставщика сохранено отдельно. Поиск учитывает название и имеющийся идентификатор поставщика, без учёта регистра и порядка слов.

Фильтрация меняет только видимые строки: выбранные поставщики, позиции и итоговый запрос сохраняются полностью. Показаны число найденных и общее число выбранных; есть очистка и отдельное сообщение об отсутствии совпадений. Запросов записи при поиске нет.

Проверки: RfqPool + PurchasingRfq — 24 теста; TypeScript — без ошибок. Проверен настоящий компонент с синтетическими данными при ширине 1536 px: без горизонтального переполнения и ошибок браузера. Поиск остаётся над прокручиваемым списком, подсказки и выбор читаемы. Проверка доступности изменённого кода: подписанное поле поиска, клавиатурная кнопка очистки, живой счётчик и табличные цифры.

Миграции нет. Правила количества, подбора и создания запроса не изменены. Независимое ревью одобрено; интегратор также просмотрел фактический снимок компонента. Полная проверка выполняется интегратором перед выпуском.
