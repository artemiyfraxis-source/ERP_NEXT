# Читаемые карточки проектов

По прямому запросу владельца переносим принятый компактный визуальный порядок в карточки «Проектов».
Номер, заказчик, этап и проблемы читаются по иерархии; длинные списки КБ заменяются точными счётчиками с доступными подробностями.
Действия, ручные отметки, ограничения доступа и логика реестра не меняются. Без backend и миграции.

## Что изменено

- На карточке постоянно видны номер проекта, заказчик, реальный статус и блокер.
- Проблемы КБ собраны в две фиксированные строки: невыданные и непроверенные ТК, ТК с погрешностями, ненабранные КБ.
- Даже проект с 40 КБ показывает только точные счётчики и не растягивает карточку. Полные списки КБ, проверки, ручные отметки, число сборок и позиций и время обновления остаются в доступном описании и подсказке.
- Карточка открывается мышью, Enter и пробелом; клавиши и действия во вложенном меню статуса не открывают проект повторно.
- Существующие действия статуса, снятия блокера и ручных отметок используют прежние API и права.
