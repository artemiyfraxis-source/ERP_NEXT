# Данные отправок: понятные сведения и печать PL

Проект и КБ первыми, внутренний номер отправки второстепенно. Меньше плашек, фактические недостающие данные и документы читаются раздельно.
Для Ульяны доступен вход в печать PL с существующими правами — дополнительные права не выдаём.
Наш курьер не требует трек-номера; внешняя ТК продолжает требовать его. Остальные условия готовности сохраняются.
Без миграции и переписывания производственных записей.

Комментарии проекта и отправки, включая очистку, уведомляют склад в той же транзакции; повтор без изменения, конфликт версии и откат уведомления не создают.
В окне отправки режим просмотра закрывает редактирование, загрузку, удаление и сохранение, включая программную отправку формы. Просмотр файла УПД и печать ПЛ доступны по существующим правам.
